# 文件夹与标签

Better Sidebar 让你将对话整理到文件夹中，并用标签快速筛选。

## 创建文件夹

1. 点击侧边栏中"文件夹"旁的 **+** 图标
2. 输入文件夹名称
3. 按回车或点击确认

文件夹支持嵌套——将一个文件夹拖入另一个文件夹即可创建层级结构。

## 将对话移入文件夹

- **拖放** — 将对话从列表中拖入文件夹
- **右键菜单** — 右键点击对话，选择 **移动到文件夹**

## 标签

标签提供了一种扁平的、跨类别的对话分类方式。

### 创建标签

1. 点击侧边栏中的 **标签** 部分
2. 点击 **+** 图标
3. 输入标签名称并选择颜色

### 应用标签

- 右键点击对话，选择 **添加标签**
- 或使用鼠标悬停对话时出现的标签图标

### 按标签筛选

点击标签部分中的任意标签，即可筛选对话列表只显示带有该标签的对话。

## 使用建议

- 用文件夹做大分类（工作、个人、学习）
- 用标签做跨分类的主题标记（Python、设计、紧急）
- 组合文件夹筛选和标签筛选，获得精确的结果
