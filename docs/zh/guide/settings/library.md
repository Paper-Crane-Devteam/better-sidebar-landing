# 资料库设置

这三项设置决定了你每次开启「资料库」标签页时的默认样貌。

前往 **设置 → 资料库**。

## 默认视图模式

控制进入资料库标签页时的默认界面：

- **树状视图 (Tree)** — 由你完全掌控的阶层目录树
- **时间线视图 (Timeline)** — 依今天 / 昨天 / 过去 7 天 / 过去 30 天 / 历史月份自动分组

你随时可以使用快捷键 `Alt+Shift+T` 或顶部 **⋯** 选单即时切换。

## 默认排序规则

- **日期 (Date)** — 最近活跃的对话排在最前
- **名称 (Name)** — 按字母顺序排列

无论选择何种排序，被标记为收藏的对话与置顶的文件夹始终固定在同层级的最顶端。

## 忽略的文件夹名称 (Ignored Folders)

输入以半形逗号分隔的文件夹名称列表，被列入的文件夹及其内部所有对话将彻底从目录树中隐藏。

```
archive, 封存, 旧专案
```

符合名称的文件夹只是被隐藏，**绝不会被删除** —— 从列表中移除该名称后，文件夹与内容立刻原封不动恢复显示。字数上限 200 字元。

:::tip
当你有想要长久保存却不想日常看见的归档资料时，这是最理想的工具。将过期专案移入「封存」文件夹并填入此处，侧边栏立刻重获清爽。
:::
