# 一般设置

「一般设置 (General)」页面包含三个小而关键的项目：扩展程序的界面语言、侧边栏快捷按钮列表，以及删除操作是否需要二次确认。

点击齿轮图示或按下 `Alt+Shift+,`，然后选择 **一般**。

## 界面语言

Better Sidebar 完整支持 7 种语言的在地化：

| 语言 | 代码 |
| --- | --- |
| English | `en` |
| 简体中文 | `zh-CN` |
| 简体中文 | `zh-TW` |
| 日本语 | `ja` |
| Português | `pt` |
| Español | `es` |
| Русский | `ru` |

切换语言会即刻全域生效 —— 包含所有标签、悬停提示、对话窗口与更新日志。首次安装时会自动根据浏览器语系自动设置。

此项设置完全独立于 Google 官方平台当前显示的界面语言。

## 侧边栏快捷链接

侧边栏底部的一组快捷图示按钮，每个项目均附有独立开关，方便你隐藏平时不常用的按钮：

**双平台通用：**
- **收藏 (Favorites)** — 跳转至「收藏」标签页
- **切换至原生侧边栏 (Switch to Original Sidebar)** — 一键切换回平台原生的侧边栏

**仅限 Gemini：**
- **My Stuff** — 前往 Gemini 我的内容
- **Gems** — 前往 Gemini Gems 管理总览
- **Notebooks** — 前往 Gemini 笔记本总览

**仅限 AI Studio：**
- **Build** — 前往 AI Studio Prompt 构建页
- **Dashboard** — 前往仪表板
- **Documentation** — 开启官方技术文件

## 操作行为设置

### 删除对话无需确认

**默认为关闭状态**，且我们强烈建议维持关闭。

若开启此项，点击删除对话时将不再弹出安全确认对话框 —— 点击的瞬间该对话便会被永久删除（包含 Google 服务器端）。

不论此开关是否开启，批量删除时始终都会弹出二度确认。

:::warning
这是全扩展程序中唯一可能因一次手误点击而造成资料遗失的设置。若需批量整理，请善用「批量模式」，在执行前清晰预览所有勾选项。
:::
