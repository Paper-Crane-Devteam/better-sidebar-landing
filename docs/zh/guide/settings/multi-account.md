# 多账号管理

如果你同时使用多个 Google 账号（个人、公司、学校），或希望为不同使用情境建立彼此隔离的整理体系，多账号设置档 (Multi-Account Profiles) 能够帮你实现彻底的资料物理隔离。每个设置档皆拥有完全独立的本地 SQLite 数据库 —— 拥有专属的文件夹结构、标签列表、收藏星号与全文索引。

![「数据与存储」中的设置档管理界面，显示活跃设置档与其绑定的账号](/images/features/multi-account.webp)

## 设置档的运行原理

一个设置档本质上就是一份独立的数据库文件。当你切换设置档时：

- 整座侧边栏会即刻重新载入该设置档的专属资料
- 文件夹、标签、收藏、提示词与片段库完全独立
- 平台上的原生对话保持不变（存储在 Google 服务器端），但它们在 Better Sidebar 中的 *组织分类方式* 会彻底隔离

如同在作业系统中切换不同的「虚拟桌面」一样。

## 建立新设置档

1. 前往 **设置 → 数据与存储**
2. 卷动至设置档列表底部
3. 点击 **新增设置档**
4. 输入易于辨识的名称（例如「工作专案」、「个人生活」、「研发实验」）并确认建立

新建立的设置档以全新的空白资料库开始，随时可切换并进行全新规划。

## 切换设置档

在设置档列表中，将鼠标悬停在未活跃的设置档上，点击出现的 **切换** 按钮：

1. 系统自动存储当前设置档的最新状态
2. 迅速挂载目标设置档的资料库
3. 侧边栏即刻更新呈现

切换速度极快，仅耗时不到一秒。

## Google 账号智慧绑定

设置档会自动记住你在该模式下登录过的 Google 账号。当你切换至「公司」设置档并造访 Gemini 时，你的工作信箱账号就会自动与该设置档绑定。

当侧边栏侦测到一个全新的 Google 账号时，会主动询问你是要将其绑定至现有设置档，还是为其建立一个全新设置档，**绝不擅自静默混杂合并**。

在侧边栏顶部随时会显示当前账号的头像，方便你随时核对。

## 各设置档独立范围与全域共用

| 随各设置档独立隔离 | 全域设置（所有设置档共用） |
| --- | --- |
| 文件夹、标签、收藏列表 | 界面语言选择 |
| 对话元数据与消息内文 | 色彩主题与外观 |
| 提示词库与片段库 | 各界面宽度与元素开关 |
| [本地快照备份历史](/zh/guide/extras/data-backup) | 自定义键盘快捷键 |
| [Google Drive 云端备份](/zh/guide/extras/drive-sync) | [功能包授权激活](/zh/guide/settings/packs) |
| Agent 工作区档案 | |

每个设置档在 Google Drive 中均拥有互不影响的独立快照档案，本地快照回滚亦彼此隔离。
