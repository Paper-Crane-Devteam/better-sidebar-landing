# 平台管理工具

点击浏览器工具栏上的 Better Sidebar 图示，会展开一个带有三个标签页的精致弹窗。这是存取各平台界面设置最便捷的入口，也是单独为特定网站彻底关闭扩展程序的唯一位置。

![包含平台、Gemini 与 AI Studio 标签页的浏览器工具栏弹窗](/images/features/platform-popup.webp)

## 「平台」标签页 (Platforms Tab)

为每个支持的网站提供一个总开关：

| 平台名称 | 网址网域 |
| --- | --- |
| Google Gemini | `gemini.google.com` |
| Google AI Studio | `aistudio.google.com` |

关闭某个平台将使 Better Sidebar **完全停止** 在该网站上运行 —— 没有侧边栏浮层、没有任何脚本注入。该网站将呈现如未安装扩展程序般的纯净原生状态。你的本地资料完全不会受到任何影响；日后随时重新开启，一切设置原样恢复。

:::warning
请勿将此开关与「切换至原生侧边栏 (`Alt+Shift+Q`)」混淆。后者只是暂时显示原生侧边栏外观，背后的资料索引、斜杠命令与 AI 助手仍正常在背景待命；而在此处关闭平台则代表彻底停用所有功能。
:::

## Gemini 与 AI Studio 专属标签页

这两个标签页直接镜像了 **设置 → 界面控制** 中的选项：各项宽度滑杆、元素可见度与附加功能开关。开启弹窗时会自动选中你当前所在的网站标签页。

### 斜杠命令开关专属于此

**斜杠命令 (Slash Commands)** 的总开关仅存在于此弹窗中，按平台独立配置。若你不希望键入 `/` 时弹出提示词库，请在此处将其关闭。

## 平台功能差异对照表

由于两个网站的原生前端架构不同，部分功能专属于特定平台：

| 功能项目 | Gemini | AI Studio |
| --- | --- | --- |
| 侧边栏、文件夹、标签、搜索 | ✅ 支持 | ✅ 支持 |
| 提示词库、片段库、斜杠命令 | ✅ 支持 | ✅ 支持 |
| AI 助手与工作区助手 | ✅ 支持 | ✅ 支持 |
| 侧边栏宽度调整 | ✅ 支持 | ✅ 支持 |
| 对话与输入框宽度调整 | ✅ 支持 | — |
| Zen 专注模式 | ✅ 支持 | — |
| 原生元素可见度自定义 | ✅ 支持 | — |
| 智能滚动条 (Smart Scrollbar) | ✅ 支持 | — |
| 划词工具栏 | ✅ 支持 | — |
| Gems 与 Notebooks | ✅ 支持 | — |
| 表格自动满宽 | ✅ 支持 | — |
| 无浮水印图片下载 | ✅ 支持 | — |
| 默认折叠 Run Settings | — | ✅ 支持 |
| 批量历史导入 | — | ✅ 支持 |
