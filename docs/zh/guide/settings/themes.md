# 主题外观

Better Sidebar 重新定义了整页的视觉美学，而不仅仅是侧边栏本身。选中一款主题，Gemini 或 AI Studio 会随之全域变幻 —— 背景、文字、强调色，在部分主题中甚至连排版字体都会焕然一新。

前往 **设置 → 主题**。

![主题格线展示，每张卡片皆带有色彩预览色带](/images/features/themes-grid.webp)

## 默认主题 (Default)

经典原生风格。简洁清爽，也是唯一支持浅色 / 深色 / 跟随系统三向切换的主题：

- **浅色 (Light)** — 纯净明亮背景配深色文字
- **跟随系统 (System)** — 自动契合你作业系统的外观设置
- **深色 (Dark)** — 深邃背景配柔和浅色文字

完全免费，也是切换其他主题时随时可复原的基准回退样式。

## 5 分钟免费试用体验

点击任意默认主题，即可在当前页面上即刻全域套用。画面上方会出现醒目提示：

> 预览模式 —— 主题将于 5 分钟后自动恢复为默认主题。

这不是缩图展示，而是在你真实的工作环境与真实对话中完整体验。5 分钟足以让你知道自己是否真正喜欢在日常中使用它。预览次数没有任何限制。

若要永久解锁所有主题，可获取 [Support Pack 主题包](/zh/guide/settings/packs)。一次买断，包含未来所有新增主题。

## AI 自定义产生主题

若这 19 款主题仍无法满足你，可吩咐 AI 为你量身打造：

1. 前往 **设置 → 主题 → 使用 AI 建立**，这会将主题产生提示词新增至你的 [提示词库](/zh/guide/sidebar/prompts-tab)
2. 在对话中使用该提示词，描述你想要的氛围意象（例如：「*深邃的午夜森林 —— 浓郁墨绿、柔和月光白、树皮棕色强调，整体温暖而非冰冷感*」）
3. 模型会回传一组完整的 JSON 结构。前往 **设置 → 主题 → 导入主题** 贴上确认即可套用
