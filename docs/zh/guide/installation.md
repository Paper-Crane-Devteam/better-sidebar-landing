# 安装

Better Sidebar 几秒钟即可安装完成并立即使用——无需账户或配置。

## Chrome

1. 访问 [Chrome 网上应用店页面](https://chromewebstore.google.com/detail/better-sidebar-for-google/cjeoaidogoaekodkbhijgljhenknkenj)
2. 点击 **添加到 Chrome**
3. 打开 [gemini.google.com](https://gemini.google.com) 或 [aistudio.google.com](https://aistudio.google.com)
4. 侧边栏会自动出现在左侧

## Firefox

1. 访问 [Firefox 附加组件页面](https://addons.mozilla.org/en-US/firefox/addon/better-sidebar-for-ai-studio)
2. 点击 **添加到 Firefox**
3. 打开 Gemini 或 AI Studio
4. 侧边栏会自动出现

## 首次启动

安装后首次打开 Gemini 或 AI Studio 时，Better Sidebar 会：

- 扫描你现有的对话并在侧边栏中显示
- 创建默认文件夹结构
- 显示简短的引导说明

:::tip
所有数据使用 SQLite WASM 存储在浏览器本地。没有任何内容发送到服务器。
:::

## 更新

扩展会通过浏览器的扩展系统自动更新。你也可以在浏览器的扩展管理页面手动检查更新。

## 卸载

要移除扩展：

1. 右键点击浏览器工具栏中的扩展图标
2. 选择 **移除扩展程序**

:::warning
卸载会删除所有本地数据（文件夹、标签、笔记）。如果需要保留数据，请先导出。
:::
