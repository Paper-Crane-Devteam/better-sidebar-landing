# 对话导出

Better Sidebar 让你以多种格式导出对话，数据始终可移植。

## 支持的格式

- **Markdown** — 干净、可读的格式，适合文档化
- **JSON** — 结构化数据，适合程序分析
- **纯文本** — 简单的文本导出

## 如何导出

### 单个对话

1. 右键点击侧边栏中的对话
2. 选择 **导出**
3. 选择格式
4. 文件将下载到默认下载文件夹

### 批量导出

1. 打开设置 → 导出
2. 选择要导出的对话或文件夹
3. 选择格式
4. 点击 **导出所选**

## 数据库备份

要完整备份所有数据（文件夹、标签、笔记和对话元数据）：

1. 打开设置 → 数据
2. 点击 **导出数据库**
3. 一个 `.db` 文件将被下载——这包含你完整的 SQLite 数据库

要恢复：

1. 打开设置 → 数据
2. 点击 **导入数据库**
3. 选择之前导出的 `.db` 文件

:::warning
导入数据库会覆盖你当前的数据。如果需要，请先导出当前状态。
:::
