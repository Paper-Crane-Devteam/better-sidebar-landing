# 提示词库

提示词库帮助你保存和复用你最好的提示词，不用每次都重新输入。

## 保存提示词

1. 从侧边栏打开提示词库（书本图标）
2. 点击 **新建提示词**
3. 输入标题和提示词内容
4. 可选择分配到某个分类

## 使用已保存的提示词

1. 打开提示词库
2. 点击任意已保存的提示词
3. 它会被插入到当前聊天输入框中

## 整理提示词

- 创建分类来分组相关提示词
- 使用库顶部的搜索栏快速查找提示词
- 收藏你最常用的提示词以便快速访问

## 同步提示词

如果你启用了 [Google Drive 同步](/zh/guide/drive-sync)，你的提示词库会在所有设备间同步。这意味着你只需构建一次，随处访问。

## 使用建议

- 保持提示词模块化——可以组合使用的小构建块
- 加入占位符文本如 `[主题]`，每次使用时填入
- 添加描述性标题，以便后续快速查找
