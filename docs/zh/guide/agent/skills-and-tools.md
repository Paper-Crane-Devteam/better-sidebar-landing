# 技能与工具列表

在 **设置 → Agent** 中，你可以精准配置每位助手允许执行的操作范围及其携带的指令规范。

页面按助手维度分别划分，确保各自职责与边界泾渭分明。

## 授权与审批政策

这三组核心开关常驻于 Agent Dock 悬浮列中的「权限设置」下，适用于任何正在执行的任务。

| 开关项目 | 默认状态 | 实际作用 |
| --- | --- | --- |
| **直接执行查询而无需询问** | 开启 | 唯读查询（SELECT 等）自动安全运行 |
| **未经许可不得直接修改资料** | **关闭** | 任何修改、删除或新增动作均会先停下来征求你的批准 |
| **自主连续执行** | 开启 | 步骤自动串连执行；关闭时每一步都需要你按 Enter 确认 |

### 为什么唯读查询默认为开启？

若每一次资料库检索（如查询文件夹 ID 或比对标签名称）都要手动弹出确认，助手将完全无法流畅工作。纯读取操作绝不会破坏任何现有资料，因此默认允许自主运行。

### 为什么修改资料默认必须审批？

因为写入具有破坏性可能。一句语意模糊的指令如果不慎将几十则对话重命名，挽回成本很高。因此默认要求在实际动手前必须由你亲自过目确认。

### 独立的「自主连续执行」开关

这项设置关注的是「回圈是否允许无人值守自动推进」。关闭它之后，你可以在每一步执行完毕后先仔细阅读模型的思考推论过程，再按下 Enter 允许它进行下一动作。

## 工具群组

### Better Sidebar 助手工具群组

**Better Sidebar 资料库工具** —— 查询与修改对话、文件夹、标签、提示词与片段库。

| 工具名称 | 具体功能 |
| --- | --- |
| `execute_sql` | 对浏览器本地 SQLite 数据库执行查询或修改 |
| `sync_conversation_messages` | 开启并记录尚无内文记录的对话历史消息 |
| `export` | 将对话打包导出为本机档案 |

### 工作区助手工具群组

**纯文本与代码工具** —— 读取、编写、精准替换与全文检索。

| 工具名称 | 具体功能 |
| --- | --- |
| `read_file` | 带行号读取纯文本/代码档案 |
| `write_file` | 建立全新档案或完整覆写档案 |
| `edit_file` | 精准替换档案内部的指定文字区块 |
| `list_files` | 浏览文件夹目录 |
| `glob_files` | 依名称规则寻找档案 |
| `grep_files` | 正规表达式跨档案搜索内文 |
| `manage_files` | 删除、移动或建立子目录 |

**富文字文件工具** —— 按大纲与章节精读并修改 Word、Excel、PDF 与 PowerPoint。

| 工具名称 | 具体功能 |
| --- | --- |
| `doc_read` | 读取文件大纲、段落章节与特定搜索 |
| `doc_edit` | 套用变更 —— 批注、修订追踪、存储格数值、页面标记 |

## 技能体系 (Skills)

技能是预先封装的专家指令卡。助手在遇到相符任务时会自动载入相应规则。

### 撰写自定义技能

在目标助手下方点击 **新增技能**，包含四个设置项：

| 字段 | 说明 |
| --- | --- |
| **标题** | 技能名称，如「每周收件匣整理」 |
| **描述** | 一句话概述功能 —— 助手依据此描述决定何时载入该技能 |
| **提示词内容** | 具体的执行指令与规范步骤 |
| **常驻载入 (Always on)** | 是否在每次启动该助手时强制载入 |

最多支持建立 20 个自定义技能。

### 优秀技能范例

技能的价值在于将反复重复的高频工作流固定下来：

```markdown
## 任务：每周收件匣整理

整理目前位于 Inbox 收件匣中的所有对话。

执行步骤：
1. 列出收件匣中的所有对话与其日期，并在采取行动前先回报总数。
2. 依主题分组。优先比对现有文件夹 —— 仅在现有文件夹确实无法容纳时才提议建立新文件夹。
3. 以表格形式呈现建议的归档对应方案，并等待用户审批。
4. 获得批准后，执行移动并套用标签。优先沿用既有标签，严禁创造语意近似的重复标签。
5. 最终回报整理结果摘要，以及无法确定归类的项目。
```
