# AI Agent 概览

Better Sidebar 内建了强大的 AI 助手。你只需用日常大白话描述任务，它就会自行拆解步骤、连续调用本地工具执行，并回报结果。

最关键的是：它完全 **透过你当前已登录的 Gemini 或 AI Studio 会话** 运行。无需填写任何 API Key、无需购买额外 Token，亦无任何第三方服务器涉入。为你服务的正是你正在聊天的原生模型，你的数据始终留在浏览器本地。

![AI 助手执行任务：建立文件夹、移动对话、批量打标签](/images/features/agent-in-action.webp)

## 两大助手模式

它们具备不同的职责与工具集，发起任务时可依需求选择其一：

| 助手模式 | 作用范围 | 专属指南 |
| --- | --- | --- |
| **Better Sidebar** | 你的对话、文件夹、标签、提示词、片段库 | [Better Sidebar 助手](/zh/guide/agent/better-sidebar-agent) |
| **Workspace (工作区)** | 私有本地工作区中的本机档案与文件 | [工作区助手](/zh/guide/agent/workspace-agent) |

Better Sidebar 助手无法存取你的本地工作区档案；工作区助手则无法视图你的对话库存。这种严格的职责分离是刻意设计的 —— 确保各助手的权限边界清晰、安全且容易理解。

## 发起任务

在任何聊天输入框中输入 `>`。画面上会弹出选取器，挑选助手模式后，输入你的任务指令并按下 Enter。

![包含操作说明与范例提示词的 Agent 标签页](/images/features/agent-launcher.webp)

这就是全部的呼叫界面。没有多余的独立对话窗口，因为助手是直接在同一对话流中调用模型来完成任务。

:::tip
侧边栏中的 **Agent** 标签页是一个功能发起站，而非聊天窗口。它汇聚了使用范例、提示词范本，以及自定义技能与工作区设置的入口。真正的互动直接在网页原生的输入框中完成。
:::

### 提示词范例

Agent 标签页内建了一系列实用范例 —— 整理历史纪录、深度穿透搜索、批量导出、同步遗失记录、重构提示词库、清理片段、记录重大决定、分析统计数据。点击任一范例即可填入输入框，发送前可随意修改。

:::tip
指令越明确，结果越精准。「帮我整理对话」通常效果有限。而「将我收件匣中未分类的对话按主题归纳，先给我看规划方案，只有在现有文件夹不适用时才建立新文件夹，并优先重复使用现有标签」则能精准交付你心中所想。
:::

## 即时监控执行进度

### 顶部悬浮状态列 (Agent Dock)

任务执行期间，聊天输入框上方会浮现常驻状态列 —— **Agent Dock**。即使关闭侧边栏它依然保持可见，集中呈现当前状态、停止按钮、授权确认提示与最终结算摘要。

### 助手视图 vs 原生视图

左上角开关可随时切换对话呈现模式：

- **助手视图 (Agent)** — 将各步骤渲染为干净易读的操作卡片，结果默认折叠收纳
- **原生视图 (Original)** — 显示未经包装的原生 JSON 请求与模型通讯全文，便于深入排查除错

### 步骤卡片

每个动作都会以浅显易懂的卡片展示 —— *检索资料中*、*修改资料中*、*读取对话内容*、*导出中* —— 并标示即时状态：执行中、已完成、失败、已拒绝、未执行。点击任一卡片可随时查看内部实际运行的详细细节。

## 掌控与安全护栏

给予 AI 资料库操作权限时，安全煞车机制是重中之重。

### 读取直接执行，写入主动征询

默认安全规范：

| 行为设置 | 默认状态 | 说明 |
| --- | --- | --- |
| **直接执行查询而无需询问** | 开启 | 唯读查询（SELECT 等）自动安全运行 |
| **未经许可不得直接修改资料** | **关闭** | 任何新增、修改或删除操作必须先弹出确认 |
| **自主连续执行** | 开启 | 步骤自动串连执行；关闭时每一步均需你按 Enter |

### 授权确认窗口

当遇到写入或修改操作时，Dock 会明确呈现其意图。你可以选择：

- **执行** 当前步骤
- **一并执行接下来的 N 个操作** — 批量批准该轮剩余动作
- **本次任务不再询问** — 仅在当前单次任务内放行自动执行
- **拒绝**，并可附带说明原因供模型修正思路

「本次任务不再询问」只对当前任务有效，下一次新任务发起时会自动恢复严谨审批。

### 复原变更 (Undo changes)

在执行过资料修改的任务结束后，总结摘要中会出现 **复原变更** 按钮。点击可将所有受影响的资料表即刻复原至任务开始前的原始状态。

:::warning
复原具有时效性：它持续有效直到你开启 *下一个* 新任务，或点击 **保留变更**。若对任务成果存疑，请务必在开启新任务前做出决定。

此外，复原是整表回滚，这段期间你手动进行的其他修改也会一并被复原。复原后请记得告知模型，以免模型基于已被复原的旧状态继续推论。
:::

批量删除前，系统均会强制先在本地自动建立 [快照备份](/zh/guide/extras/data-backup)。

### 自动防护中断

引擎内建专门的死回圈与异常侦测防护：

| 触发防护条件 | 行为机制 |
| --- | --- |
| **重复无效调用** | 相同工具搭配完全相同参数 —— 尝试 3 次发出警告，达 5 次强制中止 |
| **连续失败** | 连续多轮出错 —— 逐级提升提示介入，连续 6 次强制中止 |
| **无法解析的回复** | 重新尝试 1 次，若仍失败则停止并交由人工接管 |
| **长时间无人值守执行** | 连续无人工介入运行 20 轮后，自动暂停并发起确认签入 |

## 免费版与进阶版功能对比

| 功能项目 | 免费版 | [Power Pack 进阶包](/zh/guide/settings/packs) |
| --- | --- | --- |
| 读取资料、穿透搜索、分析统计、产出报表 | ✅ 支持 | ✅ 支持 |
| 主动修改资料 —— 归类、打标签、改名、合并、清理 | 唯读建议 | ✅ 支持直接动手执行 |
| 批量导出到 Obsidian 与 Notion | ❌ | ✅ 支持 |
| 工作区 (Workspace) | 1 个（最多 5 个档案） | 无限制 |

在免费模式下，助手处于唯读状态，但依然非常实用 —— 它能帮你统计哪些文件夹已荒废、哪些提示词从未使用过，并列出收件匣每则对话的最佳归宿建议。

## 隐私承诺

- 直接利用已登录的 Gemini 或 AI Studio 会话，无需 API Key
- 无任何额外开销或独立 Token 计费
- 所有查询均在浏览器本地的 SQLite 数据库中运行
- 绝不会传送到 Better Sidebar 的任何服务器（我们根本没有服务器）
