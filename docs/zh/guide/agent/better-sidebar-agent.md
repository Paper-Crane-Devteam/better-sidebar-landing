# Better Sidebar 助手

这款助手专门负责管理你的数据库资产：对话、文件夹、标签、提示词与片段库。它能直接向本地 SQLite 数据库发起查询，解答任何默认过滤器无法涵盖的复杂问题，并依指令采取行动。

在聊天输入框输入 `>` 并选择 **Better Sidebar** 即可启动。

![AI 助手建立文件夹、移动对话与打标签，每个步骤以卡片清晰呈现](/images/features/agent-in-action.webp)

## 它的权限与能力边界

| 操作对象 | 支持动作 |
| --- | --- |
| 对话 (Conversations) | 读取标题、时间、所属文件夹、备注说明、消息内文 |
| 文件夹 (Folders) | 建立、重命名、移动、修改颜色、删除 |
| 标签 (Tags) | 建立、重命名、套用关联、合并清理 |
| 提示词 (Prompts) | 阅读、改写、重构组织，包含变量设置与模组化引入 |
| 片段 (Snippets) | 阅读、重写标题、重新归档、去除重复项目 |

此外，它还具备三项专属能力：**同步对话消息**（开启对话以记录其正文）、**导出对话**至本机档案，以及**启动专属技能**载入特殊指令。

它无法存取你的本地工作区档案 —— 那是 [工作区助手](/zh/guide/agent/workspace-agent) 的专属职责。

## 内建技能库

技能是一组预先封装的专案专家指令集。当任务符合时助手会自动动态载入：

| 内建技能 | 应用场景 |
| --- | --- |
| **自动分类对话 (Auto-Classify Conversations)** | 依据对话内文主题，自动归类进文件夹并套用标签 |
| **回补搜索索引 (Sync Missing Messages)** | 搜索没有存储正文的对话，并逐一自动开启同步补全 |
| **导出对话 (Export Conversations)** | 条件查询并批量导出对话资料 |
| **管理提示词库 (Manage Prompt Library)** | 编写、重构与组织提示词，处理变量与模组化组合引入 |
| **管理片段库 (Manage Snippets)** | 整理、去除重复并搜索已存储的精华片段 |

各项技能均可手动停用，且支持自行撰写扩展。详见 [技能与工具设置](/zh/guide/agent/skills-and-tools)。

## 经典 Prompt 范例

这些范例非常值得完整阅读。其句式经过精心打磨 —— 每一句都对目标高度具体，并防范了潜在的边界偏差。

### 整理堆积未分类的对话

> 整理我未分类的对话：依主题分组，并先列出方案让我确认。若现有文件夹不适合，才建立新文件夹并将对话移入。最后根据对话内容打上标签，请优先重复使用现有标签以避免重复。

### 深度穿透搜索

> 寻找所有提到「Docker 部署」的内容。请彻底搜索对话、消息内文与代码片段，不要只搜索标题。由新到旧排序，为每笔结果提供一句话重点摘要，并注明存放于哪个文件夹。

### 回补搜索索引

> 检查有多少对话仅有标题而无存储消息。先依最近时间排序回报总数，然后帮我同步最新的 20 则内容，让它们出现在搜索与导出中。

### 批量导出与封存

> 将「工作」文件夹中 3 月份以来的所有对话导出为 Markdown，每则对话一个独立档案并打包成 ZIP。若有任何对话尚未同步消息内文，请在导出前先行告知。

### 重构提示词库

> 整理我的提示词库：将不容易透过 `/` 检索的项目重命名，关键词放最前面。将重复出现的「身分设置与输出格式」区块提取成独立提示词并以 import 引入。若变量选项固定，请改为下拉选单。

### 清理片段库

> 我的片段收件匣堆积了很多内容。请依主题将它们分门别类放进文件夹，并将标题简化为重点摘要。若有重复内容，请保留最旧的一则。删除前请先列出确认列表。

### 资料库审计与统计

> 为我制作一份统计报表：每个文件夹有多少对话、上个月新增了多少对话，以及哪些文件夹超过三个月未曾活跃。以此为基础，建议我哪些文件夹应该合并。

## 连续多轮自然交谈

助手会维护上下文记忆。后续对话中无需再次输入 `>`，直接自然说话即可：

> 有意思。请按月份进一步细分。
> 
> 现在对标记星号的对话也执行一次。
> 
> 算了，不如直接将那两个文件夹合并吧。

将它视为身旁的实习搭档，而非生硬的命令列工具。你随时可以向它咨询意见：

> 看看我的资料库，告诉我有哪些地方需要整理？

## 免费版 vs Power Pack 进阶包

在免费方案下，助手处于 **唯读状态**。所有资料库检索、统计分析均正常运行，只是无法直接动手修改你的数据。

即使是唯读模式，它依然是一名优秀的分析师。它能帮你找出荒废的文件夹、统计使用习惯，并列出整理建议。

[Power Pack 进阶包](/zh/guide/settings/packs) 则全面解锁主动修改权限。当遇到权限限制时，助手会明确提示，绝不产生模糊混乱的错误。
