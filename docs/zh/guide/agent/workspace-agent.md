# 工作区助手 (Workspace Agent)

「工作区 (Workspace)」是与扩展程序共存的私有档案空间。你可以将档案拖拽进去，或者吩咐助手从零开始构建，它能够直接读取、编写与精准修改这些真实档案。

在聊天输入框输入 `>` 并选择 **Workspace** 即可启动。

:::tip Beta 测试阶段
工作区助手目前处于 Beta 阶段。它已具备强大功能且对待档案极其谨慎，但在边界情况下仍可能遇到细节瑕疵。回报的问题通常能获得迅速修复。
:::

## 为什么它与一般「在对话中上传附件」截然不同？

当你在对话中上传一份 Word 档作为附件时，模型读取后会在回复中给你输出一段全新的文字。当你手动复制贴回原本的文件时，你原有的排版、样式与字型设置往往荡然无存。

**工作区助手直接编辑原始档案本体**。你的标题阶层样式、自动编号、学术引用、统计图表、条件式格式设置 —— 一律完好如初。因为它只针对你要求调整的段落进行局部修改，档案其余二进位部分完全保持一模一样。

这正是该功能的核心精髓所在。

## 如何将档案载入工作区？

两种途径：

**直接拖放** 进工作区档案目录树。对于 Word、Excel、PDF 与 PowerPoint，必须透过此方式载入，因为浏览器端无法凭空从零产生这些复杂的二进位结构。

**吩咐助手从零建立**。对于纯文本与各类代码档案，你无需手动上传任何内容：

> 帮我从零构建一个完整的 React 待办事项 Todo 应用程序。

助手会直接在工作区中建立 HTML、各元件档案、CSS 样式表与设置档。

:::warning
这是该功能最常见的误解。许多人误以为必须先上传档案才能使用。对于纯文本与代码 —— `.md`、`.txt`、`.html`、`.js`、`.ts`、`.py`、`.css`、`.json`、`.csv`、`.srt` 等 —— 助手完全具备无中生有的建立与自由修改能力。
:::

## 支持的档案格式

### 从零建立与自由编辑

所有纯文本与原始码：`.md` `.txt` `.html` `.css` `.js` `.ts` `.jsx` `.tsx` `.py` `.json` `.csv` `.yml` `.sh` `.srt` `.vtt` 等。

针对这些格式，助手具备全方位能力：建立新档、精确替换字串、正规表达式跨档案搜索、重新架构整个目录结构。

### 读取、批注与精确局部修改

以下复合二进位格式仅限已存在的实体档案：

| 格式 | 副档名 | 支持能力 |
| --- | --- | --- |
| **Word** | `.docx` `.docm` | 按大纲与章节精读。插入 **修订追踪 (Tracked Changes)** 与 **批注 (Comments)**、替换文字、调整段落与样式、插入或删除表格与列 |
| **Excel** | `.xlsx` `.xlsm` `.xltx` | 先分析表头结构再计算。设置存储格、新增字段、新增/重命名工作表、撰写真实的 Excel 公式 |
| **PDF** | `.pdf` | 读取页面文字与书签。高亮重点、新增附注便利贴、填写表单字段、加浮水印、旋转、删除、撷取与合并页面 |
| **PowerPoint** | `.pptx` | 读取与修改投影片文字、备忘稿、图形形状，调整投影片顺序 |

## 实践应用场景

### 审查论文或合约文件

> 逐章阅读 `thesis.docx`。在论点薄弱处留下批注，并以「修订追踪」的方式提出修改建议，不要直接重写整段文字。

完成后你下载该档案直接在 Word 中开启，就像导师或法务主管帮你审阅过一样，可以逐条点击「接受」或「拒绝」，你的参考文献与图表编号丝毫无损。

### 试算表统计分析

> 读取 `sales.xlsx`，新增一栏计算月对月成长率 (MoM)，并新增一个摘要工作表按地区统计总额。

助手会写入 **真正的 Excel 运算公式**，而非死板的数字。日后原始数据变更时，统计数值会自动联动更新。

### 字幕翻译与时间轴保护

> 将 `episode-03.srt` 翻译成日文并润色语气。

时间轴标记被视为神圣不可侵犯，一毫秒都不会偏移，确保字幕与影片完全同步。

### 跨对话记录重大决策

> 将本次对话的结论整理为列表，存储到工作区中的 `notes/decisions.md`。末尾附加未决问题。若档案已存在，请以今天日期进行追加，不要覆盖旧内容。

工作区档案 **跨越不同对话，且跨越 Gemini 与 AI Studio 两大平台** 始终存在 —— 在 Gemini 中建立的档案，切换至 AI Studio 依然能够读取与编辑。

## 工作区额度与限制

档案存放于具名工作区中（默认为 `default`）。

| 功能项目 | 免费版 | [Power Pack 进阶包](/zh/guide/settings/packs) |
| --- | --- | --- |
| 工作区数量 | 1 个 | 无限制 |
| 每个工作区档案数 | 5 个 | 无限制 |

免费版的 5 个档案足以让你深度体验 —— 放入一份主文件加上几份备忘笔记。
