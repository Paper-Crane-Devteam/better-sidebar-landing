# Google Drive 同步

Drive 同步能够在你的个人 Google Drive 中保存一份 Better Sidebar 整理架构的备份。更换新笔记型电脑或不小心清除浏览器快取时，不会让你数个月以来的精心分类毁于一旦。

![「数据与存储」设置中的 Google Drive 同步与本地备份控制项](/images/features/drive-sync-and-backup.webp)

## 同步内容范围

| 包含同步 | **不包含** 同步 |
| --- | --- |
| 文件夹及其代表色 | **对话消息内文** |
| 标签及其关联绑定 | |
| 收藏与置顶设置 | |
| 对话元数据（标题、时间、自定义备注） | |
| 提示词库（含变量与引入设置） | |
| 片段库 | |
| 各项偏好设置与界面自定义 | |

:::warning
对话消息内文刻意被排除在同步之外。消息内文占据了资料库 95% 以上的体积，且原本就完整保存在 Google 官方服务器端。排除内文能确保每一次云端上传极速轻巧。新电脑还原后，你的组织架构会完整复原，但全文搜索需在开启对话或委托助手补齐后才会生效。详见 [全文搜索历史资料](/zh/guide/sidebar/search-tab#导入聊天记录)。
:::

## 链接设置

1. 前往 **设置 → 数据与存储 → Google Drive 同步**
2. 点击 **链接 Google Drive**
3. 批准 Google 账号授权确认

扩展程序仅会请求其专属的应用程序隐藏文件夹权限（`drive.appdata`）。它无法窥探你云端硬碟中的任何其他档案，资料亦绝不会传送至 Google 之外的任何第三方。

## 同步机制的运行原则

### 上传全自动

开启 **自动上传** 后，每当你在本地修改了资料结构，或者每隔 25 分钟，Better Sidebar 就会在背景自动推送一份最新快照到云端。

### 下载还原永远手动

**云端资料绝不会在未经许可下自动覆盖本地**。只有当你主动点击 **从 Drive 还原** 时，云端资料才会被拉取下来。本地永远被视为最高真实来源，云端仅作为安全备援。

### 双向覆盖而非混乱合并

点击 **备份至 Drive** 会完整覆盖该账号的云端快照；点击 **从 Drive 还原** 会完整覆盖本地当前设置档。两者均不进行容易产生冲突的自动合并。

还原前，Better Sidebar 会自动在本地先建立一份防护快照，防止你误按后后悔。详见 [本地备份](/zh/guide/extras/data-backup)。

## 当两台装置发生冲突时

若云端备份已被另一台电脑更新，自动上传会主动 **暂停**，并提示：「*云端快照已在另一台装置上变更*」。

此时同步会主动冻结以保护双方资料。你可以手动决定裁决方向：

- **上传** — 以当前这台装置为准，覆盖云端
- **下载** — 以云端为准，覆盖当前这台装置

做出决定后，自动同步将恢复正常。

## 多账号设置档独立隔离

同步严格绑定于 **当前活跃的账号设置档**。每个 Google 账号在云端硬碟中均拥有互不干扰的独立快照。
