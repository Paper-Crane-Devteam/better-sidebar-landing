# 快速开始

Better Sidebar 是一个浏览器扩展，为 **Google Gemini** 和 **AI Studio** 添加强大的组织功能。完全在浏览器中运行——无需云端，无需账户，完全隐私。

## 功能概览

- **文件夹与标签** — 用嵌套文件夹和彩色标签整理对话
- **全文搜索** — 通过搜索内容即时找到任何对话
- **提示词库** — 一键保存和复用你最好的提示词
- **Google Drive 同步** — 跨设备同步设置和提示词（聊天内容保持本地）
- **多账户** — 在多个 Google 账户间切换而不丢失位置
- **对话导出** — 以多种格式导出聊天记录
- **图片下载** — 下载无水印的 AI 生成图片
- **界面自定义** — 调整侧边栏宽度、主题和布局
