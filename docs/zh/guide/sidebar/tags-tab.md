# 标签管理

标签为你提供了文件夹之外的第二维度组织维度。一则对话只能隶属于一个文件夹，但可以同时拥有任意多个标签。文件夹回答的是「这份档案存放在哪里？」，而标签回答的是「这份内容涉及哪些主题？」。

## 建立标签

1. 在「标签 (Tags)」标签页顶部的输入框键入名称
2. 按下 Enter 或点击 **+** 按钮
3. 调色盘弹出 —— 为标签挑选专属颜色（或保留默认值）
4. 完成，新标签即可投入使用

标签名称上限为 30 个字元。保持短小精悍 —— 例如「工作」、「Side Project」、「待回顾」、「重要参考」。

## 为对话加上标签

标签的套用操作在 **资料库标签页** 进行，而非在标签标签页本身。在任一对话上右键点击 → **标签** → 勾选所需套用的标签即可。

你也可以批量打标签：在资料库标签页开启批量模式，勾选多则对话，然后使用底部的「新增标签」动作。

:::tip
标签标签页是用来 *维护管理* 标签本体（建立、重命名、改色、删除）的地方；具体 *套用* 到对话时，请在资料库标签页操作。
:::

## 标签色彩

每个标签都可以自定义颜色。色彩会呈现于：
- 标签标签页中各标签名称旁
- 筛选下拉选单中
- 资料库对话列的醒目徽章中

默认色盘与文件夹色盘完全一致，方便你打造协调和谐的视觉色彩规范。

## 管理标签

### 重命名

右键点击 → **重命名**。标签名称切换为编辑框，输入新标题后按 Enter。所有已打上该标签的对话将同步更新。

### 删除标签

右键点击 → **删除**。删除标签会将该标签从所有被套用的对话上移除，但对话本身完好无损。

:::warning
删除标签无法复原。对话依然保留在原处，但两者之间的标签关联将被解除。
:::

## 运用标签进行精准筛选

- **资料库标签页** — 点击标签图示（🏷️）展开筛选器，选取一个或多个标签，画面即刻只保留符合的对话。
- **收藏标签页** — 同样支持以标签过滤星号项目。

标签筛选采用联集（OR）逻辑：如果同时勾选了「工作」与「前端」，凡是带有其中任一标签的对话都会被列出。

:::tip
高效标签策略：用文件夹划分 *专案实体*（客户 A、客户 B、个人研发），用标签标记 *状态与属性*（紧急、参考资料、待归档）。这样一来，你能跨越所有文件夹一键调出所有标记为「紧急」的对话。
:::

## 委托 AI 助手自动打标签

手动为 300 则历史对话打标签无疑是一件繁琐的苦差事。[AI 助手](/zh/guide/agent/better-sidebar-agent) 能够读取标题与对话正文并进行智慧批量归纳：

> 依据内文为我收件匣中的所有对话打上标签。优先重复使用现有的标签，不要无端创造意思相近的重复标签。在正式执行前请先列出规划列表供我确认。

最后这句话非常重要。若不加约束，AI 可能会自行发明 `coding`、`code`、`programming`、`dev` 四个相近标签。明确要求它沿用既有标签，才能让标签库始终井井有条。

你也可以吩咐它帮你整理现有混乱的标签体系：

> 视图我的所有标签，找出语意重叠或重复的项目，提出合并优化建议，确认后帮我套用。

所有变更在执行前均需确认，且事后支持随时复原。
