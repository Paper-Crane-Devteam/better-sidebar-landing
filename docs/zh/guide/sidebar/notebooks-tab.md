# 笔记本 (Gemini)

「笔记本 (Notebooks)」标签页是你在 Gemini 中管理 Notebooks 功能的大本营。Notebooks 是一种独特的对话容器 —— 它们宛如专案空间，内部可容纳多条子对话讨论与多份数据源。Better Sidebar 为你提供所有笔记本的树状视图，并可向下展开每一本笔记本内部包含的关联对话。

![笔记本标签页列出已同步的 Gemini Notebooks](/images/features/notebooks.webp)

:::tip
本标签页专属于 Gemini。AI Studio 并无 Notebooks 概念，因此在该平台上不会显示此标签页。
:::

## 扫描同步你的笔记本

点击顶部工具栏的 **扫描** 按钮（🔄）。扩展程序会调用 Gemini API 导入完整的笔记本列表。

当你在 Gemini 原生界面中建立新笔记本时，扩展程序亦会自动在背景侦测并更新资料。

## 浏览与过滤

- **即时搜索** — 点击 🔍 图示输入关键字即时过滤
- **标签筛选** — 依套用于笔记本对话上的标签进行过滤
- **仅看收藏** — 切换 ⭐ 按钮仅看已标记星号的笔记本或子对话
- **排序** — 支持字母排序与日期排序

## 操作与管理

### 开启笔记本

点击笔记本可在树状目录中展开/折叠其子对话。若要导航至笔记本主页面，右键点击 → **开启笔记本**（前往 `gemini.google.com/notebook/{id}`），或选择 **在新标签页中打开**。

### 删除笔记本

右键点击 → **删除笔记本**。安全确认对话框弹出，确认后会透过 API 彻底从 Gemini 服务器端永久删除。

### 发起新的笔记本对话

在笔记本上右键点击 → **新增 Notebook 对话**。顶部 **新增对话** 按钮右侧的下拉选单亦提供相应选项。

## 设置默认文件夹 —— 自动归档

在任一笔记本上右键点击 → **设置默认文件夹** 并选取目标文件夹。从此由该笔记本发起的所有新对话，都会自动归类至该文件夹中。

你也可以在文件夹的 **文件夹设置** 中，绑定对应的 Notebook。

:::tip
笔记本本身通常就代表一个具体专案，将其绑定到同名文件夹后，该文件夹就会成为该专案的完整档案库 —— 自动容纳笔记本对话以及你手动拖入的其他相关资料。
:::

## 笔记本内部子对话

展开任意笔记本即可视图其内部的各条讨论串。这些子对话支持与主资料库完全一致的操作功能：

- 点击直接开启对话
- 右键点击支持完整动作（重命名、移动、打标签、导出、收藏、删除）
