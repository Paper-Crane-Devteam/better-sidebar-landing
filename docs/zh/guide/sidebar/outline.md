# 对话大纲

「对话大纲 (Outline)」是位于资料库标签页底部的一个可折叠面板。它即时呈现你当前开启对话的层次结构：每一轮问答，以及模型回答内部包含的各级标题、代码区块与资料表格。

![对话大纲面板，显示轮次、嵌套标题与表格](/images/features/outline.webp)

你可以将它想像成代码编辑器中的文件大纲视图，应用到了 AI 对话之中。

## 开启方式

点击资料库标签页底部的 **OUTLINE** 字段。默认为折叠状态。

你可以拖拽其顶部边缘调整高度。如果将上方的 **Chats** 列表折叠，大纲面板会自动延展填满整个侧边栏 —— 当你沉浸在一则超长对话中且不需要频繁切换目录树时非常舒适。

## 大纲映射内容

| 层级 | 显示内容 |
| --- | --- |
| 轮次 (Turn) | 你的提问内容，附带轮次编号 |
| 轮次内部 | 各级标题 (h2/h3/h4)、标注程序语言的代码区块、标注列数的表格、图片、链接、公式 |

结构依据模型回复中的 Markdown 标题层级自动向下嵌套，条理清晰。

## 导航与跳转

点击大纲中的任意项目，页面会平滑卷动至该内容的位置。你当前正在阅读的轮次会高亮显示，点击顶部的 **定位** 按钮（准星图示）可将大纲列表本身卷动至当前焦点。

顶部的 **全部折叠** 按钮可将所有轮次折叠至仅保留提问标题 —— 这会瞬间将大纲变成一份清晰的「本次对话所有提问列表」。这通常是回顾漫长侦错流程中最快定位问题的方法。

## 内容筛选

点击漏斗图示可展开筛选标签：

- **全部** — 显示所有项目
- **标题** — 仅显示各级标题
- **代码** — 仅显示代码区块

筛选标签仅在对话中确实存在该类型元素时才会出现。

:::tip
在长时间的代码侦错过程中，**代码** 筛选器极为好用。来回交流了 15 轮后，对话中可能散落著同一函式的 8 个不同修改版本。开启代码筛选，它们会变成一份可以直接点击切换的列表，无需手动卷动寻找。
:::

## 对话内检索

大纲自带独立的全文搜索框。它会在当前对话内部搜索并将大纲目录过滤为相符项目。

这相当于当前对话的专属结构化搜索，呈现的是章节层次而非零散的关键字标记。

若要跨整个资料库检索所有历史记录，请使用专属的 [全文搜索标签页](/zh/guide/sidebar/search-tab)。

## 右键快速复制

在大纲项目上右键点击可快速执行：

- **复制提问** — 复制该轮你发送的完整提问
- **复制回复** — 复制模型在该轮产生的完整 Markdown 回答
- **复制代码** — 直接复制代码区块的原始内容

透过大纲右键复制代码，省去了在网页上反复卷动寻找复制按钮的麻烦，且只复制纯净代码，不含多余说明文字。

## 对话大纲 vs 智能滚动条

两者均能帮助你在长对话中快速移动，但设计定位截然不同：

| 特性 | 对话大纲 (Outline) | [智能滚动条 (Smart Scrollbar)](/zh/guide/ui-customization/smart-scrollbar) |
| --- | --- | --- |
| 位置 | 资料库标签页底部面板 | 浮动于对话窗口右侧 |
| 细致度 | 轮次 **以及** 其内部的标题/代码/表格 | 每则消息一个项目 |
| 搜索 | 支持 | 不支持 |
| 筛选 | 支持（标题/代码） | 不支持 |
| 支持平台 | Gemini 与 AI Studio | 仅限 Gemini |

使用智能滚动条在消息轮次之间快速穿梭；当你需要精准定位回复内部的某个特定标题、表格或代码区块时，请使用对话大纲。

## 内容为空时的疑难排解

大纲仰赖 Better Sidebar 在本地记录的消息结构。

- **「开启对话以查看大纲」** — 目前处于新对话页面，尚未选取任何对话。
- **「无大纲内容」** — 对话已开启但消息尚未被读取记录，或者该对话过于简短（未包含任何标题或代码区块）。

如果确信该对话包含大量丰富内容但大纲未载入，通常是该对话尚未被扩展程序记录。只需开启它重新读取，或参考 [全文搜索 → Gemini 历史资料处理](/zh/guide/sidebar/search-tab#gemini-历史资料处理)。若大纲与网页内容脱节，点击智能滚动条的 [清除并重新载入按钮](/zh/guide/ui-customization/smart-scrollbar#当大纲与页面不符时) 即可重新构建。
