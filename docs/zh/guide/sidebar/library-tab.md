# 资料库

「资料库 (Library)」标签页是你的工作基地。你在 Gemini 或 AI Studio 中的所有对话都会出现在这里，这也是你将混乱无章的聊天列表转变为条理分明的个人资料库的地方。

![资料库标签页，包含自定义颜色的文件夹树、筛选列与顶部工具栏](/images/features/overview.webp)

## 界面概览

资料库标签页由上至下分为几个层级：

1. **顶部工具栏** — 快速动作，如全部折叠、排序、批量模式、新增文件夹与新增对话
2. **筛选列** — 快速切换搜索、标签筛选、类型筛选与仅看收藏
3. **档案树状目录或时间线** — 你的对话与文件夹，支持自由拖拽的树状视图或按时间分组的列表
4. **批量操作列** — 进入批量选取模式时在底部浮现
5. **对话大纲** — 底部可折叠的面板，显示你当前正在阅读的对话结构。详见 [对话大纲](/zh/guide/sidebar/outline)。

你可以随时切换两种视图模式：

- **树状视图 (Tree View)** — 由你完全掌控的文件夹阶层。自由拖拽对话、嵌套嵌套、设置不同颜色。
- **时间线视图 (Timeline View)** — 系统依据最近开启时间自动将对话分组（今天、昨天、过去 7 天等）。

:::tip
长期维护建议使用「树状视图」；想要快速找回「昨天聊过的那段话」且不想手动分类时，「时间线视图」非常方便。
:::

## 文件夹管理

文件夹是你整个整理架构的骨干。支持多层嵌套、颜色标记，以及自由拖拽移动。

### 建立文件夹

有以下几种方式：

- 点击顶部工具栏的 **文件夹+** 图示
- 在目录树空白区域右键点击 → **新增文件夹**
- 在现有文件夹上右键点击 → **新增文件夹**（建立嵌套子文件夹）

新文件夹建立后会自动进入重命名状态 —— 直接输入名称并按 Enter 即可。

### 重命名

在文件夹上右键点击 → **重命名**，或聚焦该文件夹后按下 `F2`。同选单中的 **文件夹设置** 也支持同时修改名称与代表色。

### 文件夹颜色

色彩标记能大幅提升视觉扫描效率。右键点击 → **变更颜色**，可从 12 种默认色盘中挑选，或开启自定义调色盘输入任意 HEX 色码。

颜色不仅会改变文件夹图示，还会为整列带来淡淡的背景色带，一目了然。

:::tip
建议依照生活与工作领域分配颜色 —— 例如蓝色代表工作、绿色代表个人专案、橘色代表学习笔记。对话累积到 50+ 则以上时，视觉辨识效率会大幅提升。
:::

### 文件夹置顶

在文件夹上右键点击 → **置顶**。置顶的文件夹无论当前排序方式为何，都会始终固定在所属层级的最顶端。选择 **取消置顶** 即可恢复正常排序。

这是解决「活跃专案随时间不断往下沉」的最佳方案 —— 把当月最重要的两三个文件夹置顶即可。

### 自由排序

直接拖拽文件夹可在同层级内自由调整前后顺序。明确拖拽后的顺序会覆盖默认排序规则。

### 嵌套结构

文件夹支持多层向下嵌套。将文件夹拖拽至另一个文件夹内，或在父文件夹右键选单中新增。系统没有层级深度限制，通常两到三层最为舒适。

### Gem 或 Notebook 的默认文件夹 (Gemini)

开启任意文件夹的 **文件夹设置**，你会看到 **默认归属目标**。在此绑定特定 Gem 或 Notebook 后，未来只要从该 Gem 或 Notebook 发起的全新对话，都会自动归类到此文件夹中 —— 完全不需要手动整理。

绑定完成后，该文件夹的悬停工具栏会出现快捷按钮，点击可直接以该 Gem 或 Notebook 开启新对话。文件夹选单亦会新增 **新增 Gem 对话** 与 **新增 Notebook 对话** 选项。

:::tip
如果你经常使用定制 Gem，这是最省时间的神器。将「代码审查」Gem 绑定到「Code Reviews」文件夹，从此再也不用手动归档。
:::

### 删除文件夹

右键点击 → **删除**。安全防护机制：**无法删除内部仍含有对话的文件夹**。请先将对话移出或批量删除。这能彻底防止手误造成意外资料损失。

## 对话管理

来自 Gemini 或 AI Studio 的每则对话都会作为项目显示在你的目录树中。

### 开启对话

直接点击即可。若想保留当前对话并在新标签页打开，右键点击 → **在新标签页中打开**。

### 悬停提示资讯

将鼠标悬停在任一对话上，浮动提示会显示完整资讯：自定义备注、附加标签、建立时间与最后活动时间。

![悬停提示显示对话的标签、建立时间与最后活动时间](/images/features/files-rich-tooltip.webp)

最后活动时间对于定期整理极为实用 —— 你能一眼看出哪些文件夹里的对话自三个月前就再也没被开启过。

### 对话备注

右键点击 → **编辑备注** 可为对话加上注记。备注会显示在悬停提示中，且可透过资料库标签页的文字搜索直接被检索。

Google 模型自动产生的标题往往过于笼统（例如「概念理解」）。加上一句自己的备注，不用改动标题也能清清楚楚。

### 真实重命名 (True Rename)

右键点击 → **重命名**，或选取对话后按 `F2`。输入新标题并按下 Enter。

这不仅仅是本地标记 —— Better Sidebar 会将新标题即时同步回 Google 服务器端。无论在任何装置或停用扩展程序时开启，该标题都会保持更新。

### 键盘操作快捷键

目录树聚焦后支持完整的档案总管键盘操作：

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` | 移动选取游标 |
| `→` `←` | 展开 / 折叠文件夹 |
| `Enter` | 开启选取的对话 |
| `F2` | 重命名 |
| `Delete` | 删除选取项目（弹出安全确认对话框） |

### 定位目前对话

在庞大的多层目录中迷失位置？开启顶部 **⋯** 选单 → **定位目前对话**。目录树会自动展开所有父层文件夹，并将正在视图的对话卷动至可见区域。

### 收藏与置顶

在对话上右键点击 → **加入收藏**。被收藏的对话会浮动在文件夹（或根目录）的最上方，并标记 ⭐ 星号。

若要移除：右键点击 → **取消收藏**，或直接点击悬停时出现的星星图示。

### 移动对话

两种操作方式：

1. **直接拖拽** — 按住并拖进目标文件夹（仅限树状视图）
2. **右键选单 → 移动至** — 开启文件夹选择对话框，当目标文件夹距离较远或处于折叠状态时特别好用

### 标签管理

在对话上右键点击 → **标签** — 子选单会列出所有标签的核取方块。勾选或取消勾选即可新增/移除。

若在目录树中选取了多则对话，标签操作会批量套用到所有已选项目上。

:::tip
文件夹与标签职责分明：文件夹代表「这份资料存放在哪里？」，标签代表「这份资料涉及哪些主题？」。一则对话只能存在于一个文件夹中，但可以同时拥有许多标签。
:::

### 单则对话导出

右键点击 → **导出** → 选择格式：纯文本、Markdown、JSON、Obsidian 或 Notion。详见 [对话导出指南](/zh/guide/extras/export)。

### 真实删除 (True Delete)

右键点击 → **删除**。确认对话框弹出后点击确认。这是 **真正的服务器端删除** —— 该对话会彻底从 Google 服务器端移除，而不仅仅在本地隐藏。再也不会发生删不掉的幽灵对话反复出现的问题。

:::warning
删除操作无法复原。如果未来可能需要，请务必先将对话导出备份。
:::

若觉得确认窗口繁琐，可在 **设置 → 一般 → 行为** 中开启 **删除对话无需确认**。默认为关闭。批量删除则无论如何都会弹出确认。

### 隐藏对话而非删除

部分项目选单中提供 **隐藏** 选项。隐藏只会将其从侧边栏移出，完全不改动 Google 服务器端的记录 —— 透过重新执行 **导入聊天列表** 可以随时找回。

## 新增对话

### 快速建立

点击顶部工具栏的 **新增对话** 按钮（铅笔+ 图示）。如果当前选取了某个文件夹，新对话会直接建立于该文件夹内。

该按钮依不同点击方式支持三种行为：

| 点击方式 | 结果 |
| --- | --- |
| 左键点击 | 在当前标签页开启新对话 |
| 右键点击 | **临时对话** —— 不会存储进你的档案目录树中 |
| 中键点击 | 在新标签页打开新对话 |

按钮旁的下拉箭头还提供 **新增 Gem 对话** 与 **新增 Notebook 对话**（Gemini）。点击会调用你上次使用的项目，右键点击则开启搜索选取器。

### 临时对话 (Temporary Chats)

临时对话专为一次性任务设计 —— 例如测试提示词、简短的随手查询 —— 它永远不会存入你的目录树，避免污染你用心维护的资料库。

:::tip
请注意这里「临时」的含义：在 AI Studio 上，Google 仍会自动将其存储在你的 AI Studio Drive 中；Better Sidebar 只是不将其纳入你的侧边栏树中。这是为了保持清爽，而非端对端绝对隐私。
:::

### 预先命名对话

建立新对话时，树状目录中会先出现一个带有输入框的临时项目。你可以在对话传送到 Google 服务器之前，就先键入自定义标题。当第一则消息发出后，Better Sidebar 就会自动将对话命名为你的自定义名称。

若保持留白，系统会像平时一样使用 AI 自动产生的标题。

## 筛选与排序

当对话数量增加时，筛选器就显得至关重要。筛选列位于顶部工具栏下方，提供四组切换开关：

![包含搜索、标签、类型与收藏切换开关的筛选列](/images/features/files-filters.webp)

### 快速文字筛选

点击 🔍 图示（或使用快捷键）展开即时过滤框。输入时，目录树会即时筛选出相符的对话与文件夹。若子项目相符，其父文件夹会保持展开。

这属于本地即时过滤 —— 若要跨所有消息内文进行全文检索，请切换至专属的 [全文搜索标签页](/zh/guide/sidebar/search-tab)。

### 标签筛选

点击标签图示展开标签选取列表。选取一或多个标签后，仅会显示带有这些标签的对话。

### 类型筛选

点击格线图示可在不同类型间切换：

- **全部 (All)** — 显示所有项目
- **对话 (Conversations)** — 一般聊天对话
- **图片 (Images)** — 纯文本生成图片对话
- **Gems** — Gem 专属对话 (Gemini)
- **Notebooks** — 笔记本对话 (Gemini)

### 仅看收藏

点击 ⭐ 按钮即可快速筛选出所有已加入收藏的对话。与标签筛选叠加使用，能精准锁定核心资料。

### 排序方式

顶部工具栏的排序按钮可在两种规则间切换：

- **日期排序**（时钟图示）— 最近活动的对话排在最前。文件夹本身仍按字母顺序排列。
- **字母排序**（A-Z 图示）— 所有项目完全按名称字母顺序排列。

在两种模式下，被标记为收藏的对话永远置顶在同层级最前。

## 批量操作 (Batch Operations)

当你需要一口气清理、重新归档或批量为对话贴标签时，批量模式是最高效的工具。

### 进入批量模式

点击顶部工具栏的 **列表选取** 图示（☑）。目录树会切换为核取方块模式。

![批量选取模式，已选取多则对话并显示底部批量工具栏](/images/features/files-batch-operations.webp)

### 选取项目

- 点击任意对话即可切换选取状态
- 点击文件夹的方块，可一次选取/取消选取该文件夹内的所有对话
- 点击底部批量列上的 **全选**，可一次选取当前可见的所有项目（受当前筛选条件约束）
- 文件夹在部分子项目被选取时会显示半选状态 (—)

### 批量动作

底部批量工具栏显示已选数量，并提供：

| 操作 | 功能 |
| --- | --- |
| **删除** | 彻底从 Google 服务器端同步删除所有选取的对话 |
| **移动** | 开启目录选择器，将所有选取项目批量移入目标文件夹 |
| **新增标签** | 为所有选取的对话一次性套用一个或多个标签 |
| **导出** | 一次性打包导出所有已选取的对话 |

批量删除具备即时进度显示（`正在删除 14/60…`），并支持中途取消 —— 已删除的项目保持删除，其余项目停止处理。

### 退出批量模式

点击批量工具栏上的 **X**、按下 `Alt+Shift+B`，或再次点击顶部的列表选取图示。

## 视图模式

### 树状视图 (Tree View)

默认模式。由文件夹与对话组成阶层体系，你可以精准掌控每个档案的归属。

### 时间线视图 (Timeline View)

透过 **⋯** 选单 → **切换至时间线视图**（或日历图示）切换。

对话会依时间自动分组：
- **今天**
- **昨天**
- **过去 7 天**
- **过去 30 天**
- **更早**（按月份分组，如「2025 年 5 月」）

![时间线视图，对话依今天/昨天/过去 7 天分组](/images/features/files-timeline-view.webp)

时间线视图下停用拖拽排序，其余右键功能、筛选器与批量模式均可正常使用。

## 紧凑模式 (Compact Mode)

紧凑模式会完全隐藏侧边栏左侧的图示切换列，仅保留目录树本体。视觉更纯粹，画面空间更大。

从 **⋯** 选单 → **进入紧凑模式** 启用，或直接点击顶部的 **LIBRARY** 标题字样切换。

## 保持树状目录同步

Better Sidebar 需要先读取你的对话元数据才能为你整理。

### 自动读取

造访 Gemini 或 AI Studio 时，扩展程序会自动撷取当前载入的近期对话。新建立的对话默认落入 **收件匣 (Inbox)**。

### 导入聊天记录列表

平台前端默认仅载入部分近期对话。若要将历史记录完整载入，请开启顶部 **⋯** 选单 → **导入聊天记录列表**。扩展程序会依序读取所有对话的标题与元数据。

### 取得完整消息内文

全文搜索、导出以及对话大纲都需要实际的消息内文支持：

- **AI Studio** — 透过 Google Drive 导出封装进行批量导入。请参阅 [搜索 → 导入聊天记录](/zh/guide/sidebar/search-tab#导入聊天记录)。
- **Gemini** — 当你开启每则对话时会自动记录内文。若要批量补齐，可直接吩咐 [AI 助手](/zh/guide/agent/better-sidebar-agent)：「*检查有多少对话尚未存储消息，并帮我同步最近 30 则。*」
