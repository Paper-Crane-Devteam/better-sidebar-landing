# 收藏

「收藏 (Favorites)」标签页提供极简而聚焦的视图：仅列出你标记过星号的对话。没有多层文件夹、没有阶层干扰 —— 只有一份专属于重要对话的纯粹列表，点击即开。

## 哪些内容可以被收藏？

对话、提示词与片段均可被标记星号 —— 但它们不会混杂在此处。

| 项目类型 | 收藏后显示的位置 |
| --- | --- |
| 对话 | 本标签页，以及在其所属文件夹顶部置顶 |
| 提示词 | [提示词库](/zh/guide/sidebar/prompts-tab) 顶部置顶，以及专属 ⭐ 筛选器 |
| 片段 | [片段库](/zh/guide/sidebar/snippets-tab) 顶部置顶，以及专属 ⭐ 筛选器 |

收藏标签页专属于对话。各模组分立维护，确保你的收藏对话列表干净纯粹。

## 使用收藏标签页

点击任一项目即可直接开启对话，当前活跃的对话会高亮显示。

将鼠标悬停在对话上时会出现 ⭐ 图示 —— 点击可快速取消收藏并从列表中移除。

## 快速筛选

顶部提供三种筛选维度：

- **搜索** — 依对话标题即时过滤
- **标签** — 依套用的标签过滤（OR 联集逻辑 —— 符合任一所选标签即显示）
- **类型** — 依全部 / 对话 / 图片切换

## 收藏工作流

1. 在资料库标签页中，于对话上右键点击 → **加入收藏**，或直接点击悬停时出现的星星图示
2. 该对话会立即出现在「收藏」标签页中，并在资料库所属文件夹内置顶浮动

若要取消：右键点击 → **取消收藏**，或直接在收藏标签页中点击星号。

:::tip
建议将「收藏」当作当周的「工作专区 (Working Set)」—— 标记本周最活跃的 5 到 10 则对话，切换极速流畅；任务完成后取消星号即可。
:::
