# 全文搜索

再也不会丢失对话。Better Sidebar 索引你的所有对话，让你即时搜索其内容。

## 如何搜索

1. 点击侧边栏顶部的搜索栏（或使用快捷键）
2. 输入查询内容
3. 结果会随着你的输入实时出现

## 索引范围

- 对话标题
- 你的消息（提示词）
- AI 回复
- 你添加到对话中的笔记

## 搜索技巧

- 使用引号搜索精确短语：`"如何部署"`
- 搜索不区分大小写
- 结果按相关性排序
- 最近的对话排名更靠前

## 性能

搜索索引使用 SQLite FTS（全文搜索）在本地构建。即使有数千个对话，结果也能在毫秒内出现。

:::tip
当新消息添加到对话中时，索引会自动更新。无需手动重建索引。
:::
