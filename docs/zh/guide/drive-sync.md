# Google Drive 同步

Better Sidebar 提供可选的 Google Drive 同步功能，让你的设置和提示词在不同设备间保持一致。

## 同步内容

| 数据 | 是否同步？ |
| --- | --- |
| 设置和偏好 | ✅ 是 |
| 提示词库 | ✅ 是 |
| 配置 | ✅ 是 |
| 聊天内容 / 消息 | ❌ 永远不会 |
| 文件夹结构元数据 | ✅ 是 |

## 如何启用

1. 打开 Better Sidebar 设置（齿轮图标）
2. 导航到 **同步** 部分
3. 点击 **连接 Google Drive**
4. 授权扩展（仅请求 `drive.appdata` 权限范围）

## 隐私与安全

- 扩展使用 `drive.appdata` 权限范围，仅限访问 Google Drive 中的隐藏应用专用文件夹
- 扩展 **无法** 读取或修改你 Drive 中的其他任何文件
- 聊天内容和对话历史 **永远不会** 上传
- 同步由你手动发起——没有自动后台上传

## 同步到其他设备

1. 在另一台设备上安装 Better Sidebar
2. 连接同一个 Google 账户
3. 点击 **从 Drive 拉取** 下载你的设置和提示词

:::tip
每次操作是单向的。你自己选择何时推送（上传）和何时拉取（下载）。
:::
