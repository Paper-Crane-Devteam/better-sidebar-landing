# 智能滚动条 (Smart Scrollbar)

长篇对话往往难以导航，因为浏览器自带的卷轴不会告诉你内容的位置。「智能滚动条」将其替换为一张真实对话的微缩地图：每则消息一个对应项目，当前阅读的消息即时高亮，点击即刻跳转。

![浮动于 Gemini 对话旁的智能滚动条](/images/features/smart-scrollbar.webp)

:::tip
仅限 Gemini 平台。AI Studio 渲染机制不同，暂不支持。在任一平台上你都可以改用侧边栏内部的 [对话大纲](/zh/guide/sidebar/outline)，大纲更进一步 —— 它能精准定位每则回答内部的各级标题、代码区块与表格。
:::

## 启用方式

默认为开启状态。可在 **设置 → 界面控制 → 附加功能 → 智能滚动条**，或浏览器工具栏弹窗的 Gemini 标签页中切换开关。

## 三种展示尺寸

面板具备三种状态，点击面板顶部按钮即可随意切换：

### 紧凑模式 (Compact - 默认)

一条带有简短预览的精巧面板。足以分辨不同消息，且完全不干扰视野。

### 展开模式 (Expanded)

点击展开按钮，它会变身为完整的 **对话导航大纲** —— 面板更宽，预览文字更长，用户与模型发言界线更清晰，并在顶部显示总消息数。当对话超过 50 则时建议切换至此模式。

### 收缩为图示 (Collapsed)

点击折叠按钮，它会收缩为带有消息计数徽章的悬浮小圆圈。点击随时重新展开。

## 平滑导航跳转

点击任意项目，页面会平滑卷动至该则消息。当你在网页中正常卷动时，智能滚动条的高亮焦点会即时跟随你的视野位置 —— 双向保持同步。

## 当大纲与页面不符时

在分支对话或切换历史版本后，消息顺序可能偶尔出现错位。

此时智能滚动条顶部会出现一个小巧的重新整理按钮。点击它会清空扩展程序为 *当前这则对话* 存储的本地记录，并重新整理页面以重新撷取最新结构。Gemini 云端的对话完全不会受到任何影响。
