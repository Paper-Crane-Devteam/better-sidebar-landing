# 版面与宽度

Gemini 默认决定了你的对话宽度。Better Sidebar 让你拥有完全的决定权。每个宽度维度均支持滑杆微调，各项界面元素皆附有独立开关，拖动即刻即时生效。

本页涉及的所有选项均位于 **设置 → 界面控制 (UI Controls)** 中，自动呈现当前所处平台的专属选项。此外，亦可透过浏览器网址列旁的 Better Sidebar 工具栏图示开启快速设置弹窗。

![浏览器工具栏弹窗中的界面控制面板](/images/features/platform-popup.webp)

## 宽度自定义

### 侧边栏宽度

| 平台 | 调整范围 | 默认值 |
| --- | --- | --- |
| Gemini | 300–550px | 360px |
| AI Studio | 280–500px | 320px |

各平台独立记忆数值，你可以让 Gemini 拥有较宽的侧边栏，而让 AI Studio 保持精实。

:::tip
在 1080p 屏幕上，340–380px 最为适中；在 2K/4K 或带鱼屏幕上，建议拉至 450px 以上 —— 充足的宽度能彻底避免长对话标题被截断，大幅提升目录树的视图体验。
:::

### 对话内文宽度 (仅限 Gemini)

| 调整范围 | 默认值 |
| --- | --- |
| 40–100% | 46% |

控制对话消息栏的水平宽度。Gemini 原生默认偏窄；设置为 100% 时文字会延展填满整个主区域。

:::tip
不同内容适合不同宽度：代码与表格在 85–100% 时阅读体验极佳；纯文本阅读则在 55–70% 最为舒适，适当的行长能有效避免眼球疲劳。
:::

### 输入框宽度 (仅限 Gemini)

| 调整范围 | 默认值 |
| --- | --- |
| 40–100% | 42% |

独立于对话内文宽度进行设置。这意味著你可以拥有宽广的阅读区域，同时让底部输入框保持优雅精巧的居中比例。

### 表格自动满宽 (仅限 Gemini)

Gemini 默认限制了表格宽度，常导致字段较多的表格被挤压换行。开启 **表格自动满宽 (Table Auto Width)** 可解除此上限，让表格完整展现。

## Zen 专注模式 (仅限 Gemini)

Zen 模式将界面剥离至仅保留核心对话与输入框，其余无关元素全部退避。

使用快捷键 `Alt+Shift+Z`，或前往 **设置 → 界面控制 → 附加功能 → Zen 模式** 切换。启用期间画面上会显示醒目的退出按钮。

## 紧凑模式 (Compact Mode)

紧凑模式会隐藏侧边栏左侧的图示列，将完整宽度留给目录树。

可从 **⋯** 选单 → **进入紧凑模式** 启用，或直接点击顶部 **LIBRARY** 标题切换。

## 自动隐藏输入框

双平台均支持。在你向上卷动阅读对话时，输入框会自动收缩隐藏；当鼠标游标移至屏幕底部时自动恢复。在笔记型电脑屏幕上能省下可观的垂直阅读视野。

前往 **设置 → 界面控制 → 附加功能 → 自动隐藏输入框** 开启。

## 默认折叠 Run Settings (仅限 AI Studio)

AI Studio 每次开启对话均会展开侧边的 Run Settings 面板。若不常手动微调温度与安全等级，开启此项可让该面板默认保持收起。

前往 **设置 → 界面控制 → 附加功能 → 默认折叠 Run Settings** 开启。

## 界面元素可见度 (仅限 Gemini)

独立于 Zen 模式之外，你可自由隐藏特定干扰元素：

| 元素名称 | 隐藏效果 |
| --- | --- |
| **Gemini Logo** | 隐藏左上角原生商标图示 |
| **AI 免责声明** | 隐藏底部中央的「Gemini 可能会显示不准确的资讯」常驻提示 |
| **升级按钮** | 隐藏右上角的「升级方案」商业按钮 |
| **快捷键小帮手** | 隐藏右下角的键盘小图示 |

:::tip
底部免责声明通常是大家最先关闭的项目。关闭后能立刻为对话区域释放数行垂直空间。
:::

## 其他专属自定义

- **显示对话标签** — 在顶部标题列直接展示当前对话的关联标签，无需开启侧边栏即可随时查看与增删。
- **无浮水印下载** — 下载生成图片时自动去除 Gemini 的闪烁浮水印，默认开启。详见 [无浮水印图片下载](/zh/guide/ui-customization/image-download)。
- **划词工具栏** — 反白划选文字时浮现的快捷动作面板。详见 [划词工具栏说明](/zh/guide/ui-customization/selection-toolbar)。

## 浏览器工具栏图示专属设置

**斜杠命令开关** 专属于浏览器工具栏弹窗中。点击浏览器工具栏上的 Better Sidebar 图示，在对应平台标签页即可开关该功能。
