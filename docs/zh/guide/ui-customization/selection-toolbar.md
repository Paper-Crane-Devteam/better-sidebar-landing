# 划词工具栏

在 Gemini 对话中反白选取任意文字，选取区域上方会随即浮现一个小巧的工具栏。支持六种核心动作，精准作用于你选取的内容上。

:::tip
仅限 Gemini 平台。AI Studio 目前的前端结构尚未支持此功能。
:::

## 支持动作一览

| 动作名称 | 实际功能 | 默认状态 |
| --- | --- | --- |
| **引用 (Reference)** | 将划选文字作为引用区块插入到底部输入框中 | 开启 |
| **解释 (Explain)** | 吩咐 AI 深入拆解并解释选取的内容 | 开启 |
| **总结 (Summarize)** | 吩咐 AI 针对选取段落进行精简摘要 | **关闭** |
| **存储为片段 (Save as Snippet)** | 将选取的精华段落存入 [片段库](/zh/guide/sidebar/snippets-tab) | 开启 |
| **复制 (Copy)** | 带有完整 Markdown 结构地复制选取内容 | 开启 |
| **存储为 Prompt (Save as Prompt)** | 将选取内容存储至 [提示词库](/zh/guide/sidebar/prompts-tab) | 开启 |

每个动作均可在 **设置 → 界面控制 → 划词工具栏** 中单独开关，且附有总开关。建议关闭不常用的功能 —— 三个按钮的工具栏在点击时比六个按钮更加精准高效。

## 引用回复 (Reference)

这是最实用却常被低估的功能。

在 AI 的冗长回答中反白选取某个特定论点，点击 **引用**，该段文字会直接以 Markdown 引用格式填入你的输入框。接著输入你的追问即可。

这解决了在长篇回答中追问时「你刚才说的具体指什么？」引发的歧义。直接引用精确语句，模型绝不会误解你的上下文。

## 存储为片段 vs 存储为 Prompt

- **存储为片段**：保留值得留存的 AI 优秀回答，格式完好无损地进入片段库。
- **存储为 Prompt**：保存你临时发挥的出色提问句式，随后可透过 [`/`](/zh/guide/ui-customization/slash-commands) 随时调用。

## 关闭工具栏

若你习惯划选文字来辅助眼球阅读，且觉得频繁弹出工具栏有所干扰，可在 **设置 → 界面控制 → 划词工具栏** 关闭总开关。
