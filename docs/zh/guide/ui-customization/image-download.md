# 无浮水印图片下载

当 Gemini 生成图片时，Google 默认会为输出图片嵌入一层不可见的 SynthID 浮水印元数据，标记该图片为 AI 生成。Better Sidebar 能够在下载时帮你去除此自动浮水印，提供纯净未经修改的原始图片。

## 实际作用

当开启 **移除自动浮水印 (Remove Auto Watermark)** 设置时：

- 由 Gemini 生成的图片将以原始格式下载
- 下载的档案中不会附带隐形的 SynthID 元数据浮水印
- 获取与模型最初生成完全一致的纯净原档

## 如何开启

1. 开启 **设置**（齿轮图示或快捷键 `Alt+Shift+,`）
2. 切换至 **平台** 标签页
3. 在 **附加功能** 区块中找到 **移除自动浮水印**
4. 将开关切换为开启

设置将即时生效于后续的所有图片下载。

:::tip
仅限 Gemini 平台。AI Studio 的图片生成架构不同，不适用此项处理。
:::

## 重要说明

这里所指的浮水印是隐形的 *元数据浮水印 (SynthID)*，而非印在图片角落可见的文字 Logo。

:::warning
请谨慎考量浮水印移除的合规性。SynthID 旨在帮助辨识网路上的 AI 生成内容。如果你打算在公共场合或商业专案中公开图片，请遵守当地法规有关 AI 内容标示的要求。
:::
