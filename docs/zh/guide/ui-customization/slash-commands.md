# 斜杠命令

在 Gemini 或 AI Studio 的消息输入框中输入 `/`，你的 [提示词库](/zh/guide/sidebar/prompts-tab) 就会直接在游标处弹出。

![在输入框键入斜杠开启提示词选取器](/images/features/slash-command.webp)

继续打字进行过滤。使用方向键选择，按下 Enter 插入。原本键入的 `/关键字` 会被整段完整的提示词内容即刻取代。

## 智慧比对逻辑

搜索支持模糊比对与多单词匹配，例如键入 `/rev code` 能精准找出 *Review code for security issues*。比对优先从词首开始，因此标题命名方式至关重要：

| 提示词标题 | 最佳触发命令 |
| --- | --- |
| `translate-jp` | `/tr`, `/jp` |
| `Japanese translation helper` | `/ja`, `/tran`（但不如 `/jp` 直观） |

:::tip
关键字放最前面。`review-security` 明显优于 `我用来审查代码安全性的提示词`，因为打 `/rev` 就能瞬间命中。
:::

## 动态变量自动填入

如果提示词内部包含变量，插入前会弹出小巧的填空面板。

文字变量提供自由文字框；下拉选单变量则列出默认选项。完成填空后，变量值会自动完成代入，并同步解析模组化的 `@import` 依赖。

例如以下提示词：

```
请将以下内容翻译成 {{语言:英文,日文,西班牙文}}。
语气风格：{{语气:中性客观,正式商务,休闲口语}}。

{{@import:通用翻译规则}}
```

只需轻敲三下键盘并点击两次下拉选单，就能瞬间组装出一篇带有完整标准翻译规则的完整指令。

## 如何关闭该功能

该开关位于 **浏览器工具栏图示弹窗** 中 —— 点击网址列旁的 Better Sidebar 图示，切换到 Gemini 或 AI Studio 标签页，即可独立开关 **斜杠命令 (Slash Commands)**。

:::tip
这是全扩展程序唯一一个不在侧边栏设置窗口内部、而是在浏览器工具栏弹窗中的开关。若你在「设置 → 界面控制」中找不到它，请点击浏览器工具栏上的图示。
:::

如果你经常以斜杠开头打字（例如档案路径 `/usr/local/bin` 或正规表达式），可以将其关闭。
