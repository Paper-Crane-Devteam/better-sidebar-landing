# 服务条款

*最后更新：2026 年 10 月 21 日*

本条款适用于 Paper Crane Dev（下称「我们」）发布的 **Better Sidebar for Gemini & AI Studio** 及其可选配套扩展 **Better Sidebar Web Agent Connector**（合称「本扩展」）。安装或使用本扩展，即表示你同意本条款。

## 2. Support Pack 与 Power Pack

- 部分功能需要 Support Pack 或 Power Pack，可通过 Gumroad 或爱发电购买。付款、凭证和退款由这些平台按各自的条款处理。
- 一个许可证密钥可以在有限数量的浏览器 profile 中解锁对应功能。你可以在扩展设置中释放某个激活，再到别处使用。
- 请不要分享、转售或公开许可证密钥。对明显被滥用的密钥，我们可能会停用。
- 我们会尽力让已有的付费功能持续可用。但 Gemini 和 AI Studio 由 Google 运营，随时可能变化，某些功能可能因此失效或不得不移除。

## 3. 你对 Google 服务的使用

本扩展运行在 Gemini 和 Google AI Studio 之上。你对这些服务的使用，包括 AI Agent 通过你的 Gemini 对话发送的任何内容，仍然受 Google 自己的条款和政策约束。本扩展是独立项目，与 Google 没有关联，也未获其认可或赞助。

## 4. AI Agent 与 Web Agent

- AI 的输出可能出错。依赖结果之前请先检查，尤其是 Agent 整理、重命名或删除数据，或者编辑文件的时候。
- **Web Agent** 会在你的浏览器里、用你已登录的账号读取并操作网页。它做的操作，比如提交表单、发送消息、下单，都是以你的名义完成的，而且可能无法撤销。
- Web Agent 的每一步操作都需要你先批准，**你对自己批准的操作负责**，包括遵守你使用它的网站的条款。
- 请不要在银行、支付、医疗、账号安全等页面，或任何出错代价很高的地方使用 Web Agent。网页里可能藏有专门误导 AI 的指令（「提示词注入」）。
- 请不要用本扩展违反法律、访问你无权访问的系统，或向任何网站发送垃圾信息、进行自动化滥用。
