# Prompt Library

The Prompt Library helps you save and reuse your best prompts without retyping them every time.

## Saving a Prompt

1. Open the Prompt Library from the sidebar (book icon)
2. Click **New Prompt**
3. Enter a title and the prompt content
4. Optionally assign it to a category

## Using a Saved Prompt

1. Open the Prompt Library
2. Click on any saved prompt
3. It will be inserted into the current chat input

## Organizing Prompts

- Create categories to group related prompts
- Use the search bar at the top of the library to find prompts quickly
- Star your most-used prompts for quick access

## Syncing Prompts

If you enable [Google Drive Sync](/en/guide/drive-sync), your prompt library will be synced across all your devices. This means you can build your library once and access it everywhere.

## Tips

- Keep prompts modular — small building blocks you can combine
- Include placeholder text like `[TOPIC]` that you fill in each time
- Add a descriptive title so you can find the prompt quickly later
