# Installation

Better Sidebar installs in seconds and works immediately — no account or configuration needed.

## Chrome

1. Visit the [Chrome Web Store page](https://chromewebstore.google.com/detail/better-sidebar-for-google/cjeoaidogoaekodkbhijgljhenknkenj)
2. Click **Add to Chrome**
3. Open [gemini.google.com](https://gemini.google.com) or [aistudio.google.com](https://aistudio.google.com)
4. The sidebar will appear automatically on the left side

## Firefox

1. Visit the [Firefox Add-ons page](https://addons.mozilla.org/en-US/firefox/addon/better-sidebar-for-ai-studio)
2. Click **Add to Firefox**
3. Open Gemini or AI Studio
4. The sidebar will appear automatically

## First Launch

When you first open Gemini or AI Studio after installation, Better Sidebar will:

- Scan your existing conversations and display them in the sidebar
- Create a default folder structure
- Show a brief onboarding overlay explaining the key features

:::tip
All data is stored locally in your browser using SQLite WASM. Nothing is sent to any server.
:::

## Updating

The extension updates automatically through your browser's extension system. You can also manually check for updates in your browser's extension management page.

## Uninstalling

To remove the extension:

1. Right-click the extension icon in your browser toolbar
2. Select **Remove extension** (Chrome) or **Remove Extension** (Firefox)

:::warning
Uninstalling will delete all local data (folders, tags, notes). Export your data first if you want to keep it.
:::
