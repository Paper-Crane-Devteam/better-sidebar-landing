# Image Download

When Gemini generates images, Google applies an invisible SynthID watermark to the output. This is metadata embedded in the image file that marks it as AI-generated. Better Sidebar can remove this automatic watermarking, giving you clean image downloads.

<!-- IMG_PLACEHOLDER: image-download-toggle — Screenshot of the Platform Settings showing the "Remove Auto Watermark" toggle switch -->

## What It Does

When the **Remove Auto Watermark** setting is enabled:

- Images generated by Gemini are downloaded in their original form
- The invisible SynthID metadata watermark is not applied to downloaded files
- You get the raw image exactly as the model produced it

When disabled (default), Gemini's standard behavior applies and downloaded images include the watermark metadata.

## How to Enable

1. Open **Settings** (gear icon or `Alt+Shift+,`)
2. Go to the **Platform** tab
3. Under **Additional Features**, find **Remove Auto Watermark**
4. Toggle it on

The setting takes effect immediately for any new image downloads.

:::tip
This feature is Gemini-only. AI Studio handles image generation differently and doesn't apply the same watermarking process.
:::

## Important Notes

The watermark we're talking about here is the invisible *metadata* watermark (SynthID) — not a visible "Gemini" logo on the image. If you see a visible overlay on images, that's a different mechanism.

:::warning
Be thoughtful about watermark removal. The SynthID watermark helps identify AI-generated content in the wild. If you're sharing images publicly or commercially, check local regulations about AI content disclosure. Some jurisdictions are developing requirements around AI content labeling.
:::

## When It's Useful

- **Design mockups** — When you're using Gemini's image generation for design iteration and need clean source files
- **Creative projects** — Generating reference images, textures, or concept art for further editing
- **Presentations** — Clean images without metadata artifacts for professional slides
- **Personal use** — When you simply want the cleanest possible output for your own files

:::tip
Even with the watermark removed, it's good practice to keep your own records of which images are AI-generated, especially if you're using them in public-facing work.
:::
