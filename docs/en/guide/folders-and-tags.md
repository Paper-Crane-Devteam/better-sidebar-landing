# Folders & Tags

Better Sidebar lets you organize conversations into folders and tag them for quick filtering.

## Creating Folders

1. Click the **+** icon next to "Folders" in the sidebar
2. Enter a folder name
3. Press Enter or click confirm

Folders can be nested — drag a folder into another folder to create a hierarchy.

## Moving Conversations to Folders

- **Drag and drop** — Drag any conversation from the list into a folder
- **Right-click menu** — Right-click a conversation and select **Move to folder**

## Tags

Tags provide a flat, cross-cutting way to categorize conversations.

### Creating Tags

1. Click the **Tags** section in the sidebar
2. Click the **+** icon
3. Enter a tag name and select a color

### Applying Tags

- Right-click a conversation and select **Add tag**
- Or use the tag icon that appears when hovering over a conversation

### Filtering by Tag

Click any tag in the Tags section to filter the conversation list to only show conversations with that tag.

## Tips

- Use folders for broad categories (Work, Personal, Learning)
- Use tags for topics that cross categories (Python, Design, Urgent)
- Combine folder filtering with tag filtering for precise results
