# プライバシーポリシー

*最終更新：2026年10月21日*

本プライバシーポリシーは、Paper Crane Dev（「当社」）が公開する次の2つのブラウザ拡張に適用されます。

- **Better Sidebar for Gemini & AI Studio**（「Better Sidebar」）
- **Better Sidebar Web Agent Connector**（「Connector」）：Better Sidebar のオプションのコンパニオン拡張

以下、両者を総称して「本拡張」といいます。要点は次のとおりです。お客様のデータはブラウザ内に留まり、当社はお客様のチャットや整理データを受け取るサーバーを運用しておらず、データを販売したり広告に利用したりすることはありません。

## 1. ローカル優先の保存

- フォルダ、タグ、お気に入り、メモ、プロンプト、スニペット、同期したメッセージ履歴、エージェントのセッション、ワークスペースのファイルは、お客様の端末上（ブラウザ内の SQLite データベースと拡張のストレージ）に保存されます。
- Better Sidebar で作成したプロファイルごとに、それぞれ独立したローカルデータベースがあります。
- 自動バックアップは、同じローカルストレージ内に保存されるスナップショットです。
- 拡張をアンインストールするか、拡張のブラウザデータを消去すると、これらはすべて削除されます。当社が復元することはできません。

## 2. 収集しないもの

- お客様のチャット履歴、プロンプト、AI の応答、ファイル、閲覧アクティビティを当社が受け取ったり、保存したり、読み取ったりすることは**ありません**。
- 氏名、メールアドレス、電話番号などの個人情報を収集することは**ありません**。
- アナリティクス、トラッキングピクセル、広告 SDK は**使用しません**。
- お客様のデータを販売・共有することは**なく**、AI モデルの学習に使用することも一切ありません。

## 3. Gemini と AI Studio の読み取り

Better Sidebar は **gemini.google.com** と **aistudio.google.com** 上で動作し、整理と検索のためにそこで会話のタイトル、ID、メッセージを読み取ります。オプションのバックグラウンドメッセージ同期は、現在の Google セッションを使って Google 自身のサーバーから既存のチャットを取得し、ローカルに保存します。これらが当社に送信されることはありません。

## 4. AI エージェント

Better Sidebar のエージェント（BetterSidebar Agent、Workspace Agent、Browser Agent、Web Agent）は、お客様のブラウザ内にあるお客様自身の Gemini セッションを通じて動作します。エージェントの実行時、必要な情報はお客様の Gemini の会話に入力され、お客様が自分で入力または貼り付けた場合とまったく同じように Google に送信されます。これには次のものが含まれる場合があります。

- **BetterSidebar Agent：** お客様のために検索するチャットのタイトル、フォルダ、タグ、メモ。
- **Workspace Agent：** 作業を依頼したワークスペースファイルの内容。
- **Browser Agent：** 開いているタブとブックマークのタイトルと URL。オプションの `tabs`、`tabGroups`、`bookmarks` 権限を付与した後に限り、オンにしたスイッチの範囲内でのみ使用します。
- **Web Agent：** 渡したウェブページのテキスト、リンク、構造、フォームの入力値。パスワード欄が読み取られることはありません。

これらは [Google のプライバシーポリシー](https://policies.google.com/privacy) および Gemini の規約に基づいて Google が処理します。エージェントは API キーも当社のサーバーも使用しません。

## 5. Web Agent と Web Agent Connector

Web Agent はオプション機能で、リスクに関する注意事項に同意するまではオフになっています。ページを操作するために Chrome のページデバッガーを使用しますが、この権限は Better Sidebar ではなく、別の Connector 拡張が保持しています。

Connector は次のように動作します。

- Better Sidebar からのリクエストのみを受け付け、ウェブサイトや他の拡張からのリクエストは一切受け付けません。
- Web Agent に渡したタブにのみアタッチし、Chrome はそれぞれのタブに「このブラウザのデバッグを開始しました」というバーを表示します。
- Gemini、AI Studio、Chrome ウェブストア、Google のログインページ、ブラウザの内部ページは操作を拒否します。
- ページの内容は Better Sidebar にのみ返し、どのサーバーにも送信しません。
- 保存するのは、アタッチ中のタブの ID（ブラウザを閉じると消去）と「一時停止」の設定のみです。

Web Agent がページから読み取った内容は、第4節のとおりお客様の Gemini の会話に入力されます。Web Agent がウェブサイト上で行う操作（フォームの送信、メッセージの送信など）は、そのウェブサイトからはお客様自身の操作として扱われます。

## 6. ブラウザの外に出るデータ

お客様が Gemini と AI Studio を通じて Google に送信するもの以外で、データがブラウザの外に出るのは次の場合のみで、いずれもお客様の操作によって開始されます。

- **Google Drive 同期（オプション）：** 整理データ（フォルダ、タグ、お気に入り、メモ、タイトル付きのチャット一覧、プロンプト、スニペット、Gem とノートブックの一覧）が、お客様自身の Google Drive 内の非表示のアプリ専用フォルダ（`drive.appdata` スコープ）に保存されます。拡張から Drive 内の他のファイルを見ることはできません。メッセージ履歴は同期されません。Drive を接続すると変更は自動でアップロードされますが、復元は常に手動です。接続はいつでも解除できます。
- **Notion へのエクスポート（オプション）：** Notion にエクスポートすると、選択したコンテンツと Notion インテグレーショントークンが `api.notion.com` に送信されます。トークンはブラウザ内にローカル保存されます。
- **Obsidian へのエクスポート：** `obsidian://` リンクを通じてお使いのコンピュータ上の Obsidian を開きます。ネットワークを経由するものはありません。
- **ライセンスの有効化：** Support Pack または Power Pack を有効化すると、キーの確認と有効化数のカウントのために、ライセンスキーと拡張が生成したランダムなデバイス ID が当社のライセンスサーバーに送信されます。それ以外は何も送信されず、アカウントも不要です。購入は Gumroad または Afdian が取り扱い、それぞれのプライバシーポリシーが適用されます。
- **テーマ：** 一部のテーマは Google Fonts（`fonts.googleapis.com`）からフォントを読み込みます。Google Fonts 側には、お客様のブラウザからの通常のウェブリクエストが見えます。

## 7. 権限

**Better Sidebar**

- `storage`、`unlimitedStorage`：データと設定をローカルに保存するため。
- `offscreen`：ローカルの SQLite データベースを実行するため。
- `alarms`：バックグラウンドメッセージ同期、バックアップ、Drive 同期をスケジュールするため。
- `scripting`：Gemini と AI Studio のページにサイドバーを追加するため。
- `identity`：オプションの Drive 同期のために Google にログインするため。
- `gemini.google.com` と `aistudio.google.com` へのホストアクセス：これらのサイトでサイドバーを表示し、チャットを読み取るため。
- `sidePanel`、`contextMenus`、`declarativeNetRequestWithHostAccess`（Chrome）：Chrome のサイドパネルで Web Agent を開き、「Web Agent にこのページを操作させる」メニュー項目を追加し、そのパネル内で Gemini を読み込めるようにするため。
- オプションの `tabs`、`tabGroups`、`bookmarks`：Browser Agent をオンにしたときにのみリクエストします。
- オプションの `api.notion.com` へのアクセス：Notion へのエクスポートを設定したときにのみリクエストします。

**Web Agent Connector**

- `debugger`：第5節のとおり、Web Agent に渡したタブを操作するため。
- `storage`：アタッチ中のタブと「一時停止」の設定を記憶するため。

## 8. お客様による管理

- Better Sidebar の設定からいつでもデータをエクスポートでき、ローカルバックアップから復元できます。
- バックグラウンド同期、Drive 同期、各エージェントはいつでもオフにできます。
- Web Agent は、Chrome のデバッグバーの「キャンセル」、サイドパネルを閉じる、または Connector の「Disconnect all」/「Pause」で停止できます。
- いずれかの拡張をアンインストールすると、そのローカルデータが削除されます。

## 9. 子ども

本拡張は13歳未満の子どもを対象としておらず、当社が子どもからデータを意図的に収集することはありません。
