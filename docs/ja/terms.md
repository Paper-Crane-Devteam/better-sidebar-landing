## 3. Google サービスのご利用

本拡張は Gemini と Google AI Studio の上で動作します。これらのサービスのご利用（AI エージェントがお客様の Gemini の会話を通じて送信する内容を含む）には、引き続き Google 自身の規約とポリシーが適用されます。本拡張は独立したプロジェクトであり、Google と提携しておらず、Google による承認や後援も受けていません。

## 4. AI エージェントと Web Agent

- AI の出力は誤っている場合があります。結果を信頼する前に確認してください。特に、エージェントがデータを整理、名前変更、削除するときや、ファイルを編集するときはご注意ください。
- **Web Agent** は、お客様のブラウザ内で、ログイン済みのアカウントを使ってウェブページを読み取り、操作します。フォームの送信、メッセージの送信、注文などの操作はお客様の名義で行われ、取り消せない場合があります。
- Web Agent の各操作は実行前にお客様が承認するものであり、**承認した操作の責任はお客様にあります**。これには、使用するウェブサイトの規約を守ることも含まれます。
- 銀行、支払い、医療、アカウントのセキュリティに関わるページや、ミスによる損失が大きい場所では Web Agent を使用しないでください。ウェブページには、AI を誤った方向へ導くための隠された指示（「プロンプトインジェクション」）が含まれている場合があります。
- 法律に違反する目的、アクセス権のないシステムへのアクセス、またはウェブサイトへのスパム送信や自動化された不正行為に本拡張を使用しないでください。
