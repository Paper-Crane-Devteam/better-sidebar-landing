# スマートスクロールバー

長い会話は、スクロールバーが何も伝えないので移動が難しいです。Smart Scrollbar はそれを実際の会話のマップに置き換えます。メッセージごとに 1 エントリ、読んでいるものがハイライト、クリックでジャンプ。

![Gemini 会話の横に浮かぶ Smart Scrollbar](/images/features/smart-scrollbar.png)

:::tip
Gemini のみ。AI Studio は会話の描画が違い、未対応です。どちらのプラットフォームでも [アウトライン](/en/guide/sidebar/outline) が使えます。そちらはより深く — メッセージだけでなく、各回答内の見出し、コードブロック、表をマップします。
:::

## オンにする

デフォルトでオンです。スイッチは **設定 → UI コントロール → 追加機能 → Smart Scrollbar**、またはブラウザツールバーポップアップの Gemini タブにあります。

## 3 つのサイズ

パネルには 3 つの状態があり、ヘッダーのボタンで切り替えます。

### コンパクト（デフォルト）

短いプレビュー付きメッセージエントリの細い帯。メッセージを見分けられる程度で、無視できるほど小さい。普段はここに置きます。

### 展開

展開ボタンをクリックすると完全な **会話アウトライン** になります — 広いパネル、長いプレビュー、あなたのメッセージとモデルの明確な分離、ヘッダーにメッセージ総数。

会話が 50 メッセージを超え、短いプレビューでは区別できなくなったときに切り替える価値があります。

### アイコンへ折りたたみ

折りたたみボタンをクリックすると、メッセージ数バッジ付きの小さなフローティングアイコンに縮みます。クリックでパネルが戻ります。

画面をすっきりさせたいが、機能をオフにするために設定を掘りたくないときに使います。

## ナビゲーション

任意のエントリをクリックすると、そのメッセージへスムーズにスクロールします。ページを普通にスクロールするとハイライトが位置を追跡し — マップとページは双方向で同期します。

:::tip
長いデバッグやコードレビューセッションで元が取れます。モデルの 5 回目の試みと最初を絶えず比べる必要があるとき。エントリのクリックは瞬時、スクロールで探すのは 10 秒かかり思考の流れを切ります。
:::

## アウトラインがページと一致しないとき

たまにエントリが画面上のものと揃いません — 多くの場合、会話を分岐したあと、または Gemini が予期しない方法で再描画したあとです。

そのとき Smart Scrollbar 上部に小さなクリアボタンが出ます。クリックすると、Better Sidebar が *現在の会話だけ* のために保存したメッセージを削除し、ページを再読み込みして最初から再取得します。

:::warning
これは拡張機能が保存したその会話のメッセージのコピーを消し、再読み込みで再取得されるまで全文検索から一時的に落ちます。Gemini 上の会話自体には触れません。クリーンアップ中に予期しないものを検出すると、データを危険にさらすより中止します。
:::

## 相性の良いもの

- [Zen Mode](/en/guide/ui-customization/layout-and-width#zen-mode-gemini-only) — 広いチャット、クロムなし、横にマップ
- [アウトライン](/en/guide/sidebar/outline) — メッセージではなく特定のコードブロックや見出しを探すとき
- [選択ツールバー](/en/guide/ui-customization/selection-toolbar) — メッセージへ飛び、良い部分をハイライトし、スニペットとして保存
