# ライブラリ

ライブラリタブを開いたときの見た目を決める設定が 3 つあります。

**設定 → ライブラリ**

## デフォルト表示モード

ライブラリタブの開始表示：

- **ツリー** — フォルダ階層
- **タイムライン** — Today / Yesterday / Previous 7 Days / Previous 30 Days / それ以前の月でグループ化された会話

いつでも `Alt+Shift+T` または **⋯** メニューで切り替えられます。この設定は開始位置だけを決めます。

:::tip
実際にフォルダ構造を作りそこで暮らしているならツリー。主に「昨日やっていたこと」が欲しく、整理にあまり投資していないならタイムライン。タイムラインはセットアップなしで役立つので、最初の数週間の既定として合理的です。
:::

## デフォルトの並べ替え順

- **日付** — 直近アクティブが先
- **名前** — アルファベット順

お気に入りとピン留めフォルダは、並べ替えに関係なくコンテナ内で常に先頭に浮上します。

:::tip
プロジェクトフォルダ内の日付並べ替えは現在の作業を先頭に保ちます。ルートの名前並べ替えはフォルダを見つけやすくします。設定はグローバルなので、多くの人は日付を選び、重要なフォルダを見える場所に保つために [ピン留め](/en/guide/sidebar/library-tab#pinning-folders-to-the-top) に頼ります。
:::

## 無視するフォルダ

ツリーから完全に隠すフォルダ名のカンマ区切りリスト。

```
archive, temp, old drafts
```

一致するフォルダとその中身がライブラリタブから消えます。削除はされません — このリストから名前を外せば、フォルダは元どおり戻ります。

最大 200 文字。

:::tip
残したいが見たくないアーカイブにぴったりのツールです。昨年の作業を `archive` フォルダへ移し、ここに `archive` を追加すれば、何も削除せずツリーがきれいになります。必要なときはしばらく欄を空にします。
:::

:::warning
一致はパスではなくフォルダ **名** です。別の場所に `temp` が 2 つあれば、両方隠れます。
:::
