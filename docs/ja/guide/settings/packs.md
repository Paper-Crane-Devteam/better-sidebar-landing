# パック

Better Sidebar の整理ツールは無料で、今後も無料です。任意の買い切りが 2 つあり、追加機能を足し、開発を支えます。

**設定 → パック**

## 得られるもの

| | 無料 | Support Pack | Power Pack |
| --- | --- | --- | --- |
| 価格 | $0 | $5 | $19.99 |
| | 永久 | 買い切り、生涯 | 買い切り、生涯 |

### 無料

拡張機能を入れる価値があるもののすべて：

- フォルダ、タグ、色、ピン留め、ドラッグ＆ドロップ、一括操作
- 連鎖フィルター付き全文検索
- プロンプトライブラリ、変数、合成、スラッシュコマンド
- スニペット、会話アウトライン、Smart Scrollbar、選択ツールバー
- Gems、Notebooks、マルチアカウントプロファイル
- Markdown、プレーンテキスト、JSON へのエクスポート
- Google Drive バックアップとロールバック付きローカルバックアップ
- エージェント、**読み取り専用** — クエリ、分析、報告

アカウント不要、サインアップ不要、催促画面なし。

### Support Pack — $5

テーマと、ありがとうを言う方法。

- 19 のプレミアムテーマプリセットをすべて恒久アンロック
- 今後のテーマも追加料金なし
- AI 生成カスタムテーマのインポート
- カスタムテーマスロット無制限

詳しくは [テーマ](/en/guide/settings/themes) を参照してください。

### Power Pack — $19.99

Support Pack のすべてに加え、エージェントが読み取り専用でなくなります。

- **エージェントの書き込み** — フォルダ作成、会話移動、一括タグ、改名、マージ、クリーンアップ
- **無制限のワークスペースとファイル**（無料は 1 ワークスペース、5 ファイル）
- **Obsidian と Notion へのエクスポート**、単体と一括

詳しくは [エージェント概要](/en/guide/agent/overview) と [ワークスペースエージェント](/en/guide/agent/workspace-agent) を参照してください。

:::tip
正直な決め方：無料のエージェントは、ライブラリに *何をするか* を正確に教えてくれます。走らせ、計画を読み、実行してほしいかどうか見る。明らかに「はい」なら、それを実行するボタンが Power Pack です。計画が役に見えなければ、買わないでください。
:::

## アクティベート

トークンを **設定 → パック** に貼り、**アクティベート** をクリック。

受け入れる形式：

| 出典 | 形式 |
| --- | --- |
| Gumroad | `XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX` |
| 爱发电 | `BS-SP-XXXXXXXX`（Support）/ `BS-PP-XXXXXXXX`（Power） |

## アクティベーション枠

1 ライセンスで **10 アクティベーション**、ブラウザプロファイルとパソコンをまたぎます。

アクティベーションは **ブラウザプロファイル** ごとに消費されます。実務で何を意味するか：

| 状況 | 使用枠 |
| --- | --- |
| 1 台のパソコンの Chrome プロファイル 1 つ | 1 |
| 同じパソコンの仕事用と個人用 Chrome プロファイル | 2 |
| 同じパソコンの Chrome と Firefox | 2 |
| ノート PC とデスクトップ、各 1 プロファイル | 2 |
| 1 つのブラウザプロファイル内の複数 Better Sidebar [プロファイル](/en/guide/settings/multi-account) | 1 |

最後の行を多くの人が間違えます。Better Sidebar 自身のマルチアカウントプロファイルは無料で、ブラウザプロファイルのアクティベーションを共有します。枠を使うのは別々の *ブラウザ* プロファイルです。

通常利用には 10 は十分です。意図的にマシンをまたいで広げない限り足りなくなりません。

### 枠の解放

パソコンを変える、またはブラウザを再インストール？ 離れるプロファイルで **設定 → パック** を開き、**このアクティベーションを解放** を選びます。

そこでプレミアム機能がオフになり、枠が空きます。同じトークンであとから再アクティベートできます。

*「10 のアクティベーション枠がすべて使用中です」* と出たら、もう使わないプロファイルで設定を開き、解放してください。

:::warning
ブラウザプロファイルを消す、またはマシンを引退させる *前に* 枠を解放してください。解放はその枠を持つプロファイル上で実行する必要があります。すでにアクセスを失った場合はサポートに連絡すれば解決できますが、10 秒の後始末で避けられる往復です。
:::

## ライセンス確認

拡張機能はライセンスサーバーと定期的に再検証します。

### サーバーに届かない場合

通知が出て、**ライセンスは有効のまま** です。バックグラウンドで再試行が続き、通知はそれでも有効な期間を伝えます。ネットワークが悪い日だからといって壊れません。

よくある原因：VPN やプロキシがリクエストをブロック。続くならまずそこを確認してください。

### ライセンスが本当に拒否された場合

理由は 3 つあり、拡張機能がどれかを伝えます。

| 理由 | 起きたこと |
| --- | --- |
| **Revoked** | 通常は返金またはチャージバックのあと |
| **Slots full** | 10 枠すべて使用中で、このものがもう含まれない |
| **Not recognized** | サーバーがこのトークンを知らない |

どれかが誤りだと思うならサポートに連絡してください。小さな個人プロジェクトです — 実在の人がメールを読みます。

## 買う前に試す

**テーマ** — 任意のプレミアムテーマをクリックすると、実際のページで本物の 5 分プレビュー。回数無制限。詳しくは [テーマ](/en/guide/settings/themes#free-5-minute-preview) を参照してください。

**エージェント** — 読み取り専用の半分は無料で恒久。ライブラリに何をするかを正確に教えてくれます。

**Workspace** — 1 ワークスペース、5 ファイル。本物の文書レビューや小さなプロジェクトを走らせ、働き方に合うか知るのに十分です。

どれもcrippledデモではありません。境界付きの本物の機能です。
