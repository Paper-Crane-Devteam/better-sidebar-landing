# インストール

数秒でインストールできます。アカウント作成も、初期設定も、サインアップも不要です。

## Chrome および Chromium ブラウザ

1. [Chrome Web Store のページ](https://chromewebstore.google.com/detail/better-sidebar-for-google/cjeoaidogoaekodkbhijgljhenknkenj) を開く
2. **Chrome に追加** をクリック
3. [gemini.google.com](https://gemini.google.com) または [aistudio.google.com](https://aistudio.google.com) を開く

同じビルドが Edge、Brave、Arc、Vivaldi でも使えます — Chrome Web Store からインストールしてください。

## Firefox

1. [Firefox Add-ons のページ](https://addons.mozilla.org/en-US/firefox/addon/better-sidebar-for-ai-studio) を開く
2. **Firefox に追加** をクリック
3. Gemini または AI Studio を開く

:::warning
Google Drive 同期は Firefox では利用できません — Firefox が公開していない identity API が必要なためです。それ以外は動作し、[ローカルバックアップ](/en/guide/extras/data-backup) と手動のデータベースエクスポートで同じ目的をカバーできます。
:::

## サインインが必須です

Better Sidebar はアカウントに紐づきます。プラットフォームのページで Google アカウントにサインインした **あと** に有効になります。サインアウト状態で Gemini を開いても、サインインするまで何も表示されません。

検出されたアカウントが、データの所属先プロファイルになります。詳しくは [マルチアカウント](/en/guide/settings/multi-account) を参照してください。

## 初回起動

インストール後の初回訪問では、次の画面が出ます。

1. **ウェルカム画面** — 拡張機能の説明
2. **チャット一覧のインポート提案** — 受け入れる価値があります。しないと、プラットフォームが表示している会話だけが見えます。詳しくは [チャット一覧をインポート](/en/guide/sidebar/library-tab#import-chat-list) を参照してください。
3. **任意のガイドツアー** — サイドバーの各タブの紹介

新しい会話はデフォルトで **Inbox** フォルダに入ります。フォルダ構成を決めているあいだも、何も失われません。

:::tip
インポートはぜひ実行してください。直近 20 件だけ見えるサイドバーと、これまでのすべてが見えるサイドバーの違いになります。すぐに終わりますし、あとから **⋯** メニューでもいつでも実行できます。
:::

## 言語

インストール時、ブラウザのロケールから表示言語が推定されます。対応は 7 言語です — 違っていたら **設定 → 一般 → 言語** で変更できます。

## 更新

ブラウザは拡張機能を自動更新します。強制的に確認したい場合は、ブラウザの拡張機能管理ページから行えます。

更新後は、リリース概要と完全な changelog へのリンクがある **What's New** ダイアログが表示されます。閉じたあとも **設定 → について → 変更履歴を表示** から再度開けます。

## サイドバーが出ないとき

1. そのページで Google にサインインしているか確認する
2. 再読み込みする
3. [ブラウザツールバーのポップアップ](/en/guide/settings/platform-manager) で、そのプラットフォームがオフになっていないか確認する
4. ブラウザで拡張機能が有効か確認する

プラットフォームの UI 更新で一時的に壊れることがあります。昨日まで動いていたのに今日動かない場合は、拡張機能を更新し、アプリ内の **フィードバック** タブから報告してください — こうした問題はすぐ直ることが多いです。

## アンインストール

拡張機能アイコンを右クリック → **拡張機能を削除**。

:::warning
アンインストールするとローカルデータベースが削除されます — フォルダ、タグ、お気に入り、プロンプト、スニペットのすべてです。

残したいものがある場合は **先にエクスポート** してください：**設定 → データとストレージ → エクスポート** で、再インストール後にインポートできる単一の `.db` ファイルが得られます。[Drive バックアップ](/en/guide/extras/drive-sync) もアンインストール後に残りますが、メッセージ本文は含まれません。
:::
