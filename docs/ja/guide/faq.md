# よくある質問

## 料金とライセンス

### Better Sidebar は無料ですか？

整理ツールは無料で、今後も無料です。フォルダ、タグ、検索、プロンプト、スニペット、Markdown へのエクスポート、バックアップ、読み取り専用モードのエージェント。アカウントは不要です。

任意の買い切りが 2 つあり、追加機能を足せます — テーマが $5、エージェントに変更を許可するのが $19.99。詳しくは [パック](/en/guide/settings/packs) を参照してください。

### オープンソースですか？

はい、GPL-3.0 です。[GitHub のソース](https://github.com/Paper-Crane-Devteam/better-sidebar-for-google-ai-studio)。

### サブスクリプションはありますか？

ありません。どちらのパックも買い切りで、7 日間の無条件返金があります。

### ライセンスは何台まで使えますか？

アクティベーションは 10 枠で、*ブラウザプロファイル* ごとに 1 枠を消費します。同一ブラウザ内の Better Sidebar マルチアカウントプロファイルは追加枠を使いません。詳しくは [アクティベーション枠](/en/guide/settings/packs#activation-slots) を参照してください。

## プライバシー

### データはどこに保存されますか？

ブラウザ内のローカル SQLite データベース（WASM、OPFS 上）です。Better Sidebar のサーバーはありません。[プライバシーポリシー](/en/privacy) を参照してください。

### エージェントはデータをどこかに送りますか？

エージェントは既存の Gemini または AI Studio セッション経由で動きます。API キー不要、追加料金なし、第三者サービスなしです。

Google に届く内容は、手でメッセージを打つときと同じです。プロンプトと、回答のためにエージェントが読んだデータです。ホスト済みモデルの上で動かす以上、避けられません — ただし Google がすでに関わっている場所以外には行きません。

### ホスト権限が必要な理由は？

Gemini と AI Studio のページで動くためです。サイドバーの注入、会話タイトルと ID の読み取り、検索用のメッセージ内容の取得。要求するのはこの 2 サイトだけです。

Notion API へのアクセスは *別途オプション* の権限で、Notion 連携を有効にしたときだけ要求されます。

## プラットフォーム

### Gemini と AI Studio の両方で動きますか？

はい。2 つのサイトの作りが違うため、一部機能はプラットフォーム固有です — Zen Mode、Smart Scrollbar、選択ツールバー、Gems、Notebooks は Gemini 専用。一括履歴インポートは AI Studio 専用。[比較表](/en/guide/settings/platform-manager#platform-differences) を参照してください。

### ChatGPT や Claude では動きますか？

現時点では動きません。

### どのブラウザ？

Chrome Web Store から Chrome および任意の Chromium ブラウザ（Edge、Brave、Arc、Vivaldi）、Add-ons から Firefox。

Google Drive 同期は Firefox では使えません — Firefox が公開していない identity API が必要です。[ローカルバックアップ](/en/guide/extras/data-backup) はどこでも使えます。

### シークレット（Incognito）では動きますか？

拡張機能は、ブラウザの拡張機能設定で手動有効にしない限りシークレットでは動きません。有効にしても、シークレットセッションの保存データは残らないことがあります。

### Gemini が遅くなりますか？

なりません。オーバーレイとローカルデータベースです。ホットパスにネットワーク往復はありません。

## データが見つからない

### 古い会話がサイドバーにない

自動で拾われるのは直近の会話だけです。**⋯ メニュー → チャット一覧をインポート** で一覧全体を取り込みます。[ツリーを同期し続ける](/en/guide/sidebar/library-tab#keeping-the-tree-in-sync) を参照してください。

### 検索で古い会話が見つからない

チャット一覧のインポートは *タイトル* を取り込み、*メッセージ* は取り込みません。全文検索にはメッセージ本文が必要で、それは別ステップです。

- **AI Studio** — Drive エクスポートからの一括インポート
- **Gemini** — 各チャットを開くと内容が記録されるか、[エージェント](/en/guide/agent/better-sidebar-agent#sync-missing-messages) に一括同期を依頼

詳細は [検索](/en/guide/sidebar/search-tab#import-chat-history) にあります。

### 一部の会話が空のまま同期される

ごく古い会話は、Google 側からもう取得できないことがあります。エージェントは成功したふりをせず、空で返ってきたものを報告します。その場合、復元できるものはありません。

### アウトラインが画面と一致しない

多くの場合、会話を分岐したあとに起きます。[Smart Scrollbar](/en/guide/ui-customization/smart-scrollbar#when-the-outline-doesnt-match-the-page) のクリア＆再読み込みボタンで、その会話の保存済みメッセージを再構築できます。

## エージェント

### API キーは必要ですか？

不要です。既存セッションを使います。

### トークン料金はかかりますか？

別予算はありません。自分でモデルに話しかけるのと同じです — 実際にやっていることがそれだからです。

### 誤って削除しませんか？

書き込みはデフォルトで承認を求め、データを変えたタスクのあとには **変更を元に戻す** ボタンがあります。アンドゥの窓は次のタスク開始で閉じます。一括削除の前には自動で [ローカルバックアップ](/en/guide/extras/data-backup) が取られます。

[コントロールを保つ](/en/guide/agent/overview#staying-in-control) を参照してください。

### 途中で止まってループだと言われた

意図的です。エンジンは同一ツール呼び出しの繰り返しや連続失敗を検知し、無理に続けず中断します。何をしたかを読んでから、言い直すか最初からやり直してください。[自分で止まる](/en/guide/agent/overview#it-stops-itself) を参照してください。

### 「12 ステップを単独で実行しました」と一時停止した

チェックインであり、エラーではありません。長時間の無人実行のあと、続ける前に確認できるよう一時停止します。**続ける** か **ここで止める** を選んでください。

## データの安全

### ブラウザのデータを消したらどうなりますか？

Better Sidebar のデータベースも一緒に消えます。[Drive 同期](/en/guide/extras/drive-sync) か、ときどきのデータベースエクスポートで備えてください。

Drive 同期にはメッセージ本文は含まれません — 完全なコピーには **設定 → データとストレージ → エクスポート** を使います。

### 別のパソコンにデータを移せますか？

はい、2 通りあります。Drive 同期（構造のみ、メッセージなし）か、データベースのエクスポート／インポート（すべて）。詳しくは [バックアップと復元](/en/guide/extras/data-backup) を参照してください。

### Better Sidebar で会話を削除すると Google 側も消えますか？

はい。削除はサーバー側の本物の削除です。サイドバーからだけ消したい場合は、使える場所では **非表示** を使ってください。

## トラブルシューティング

### サイドバーが出ない

1. Google アカウントにサインインしているか確認する — 拡張機能はアカウントに紐づく
2. [ツールバーのポップアップ](/en/guide/settings/platform-manager) でプラットフォームがオフになっていないか確認する
3. ページを再読み込みする
4. ブラウザで拡張機能が有効か確認する

### さっきまで動いていたのに止まった

多くの場合、プラットフォームの UI 更新です。拡張機能を更新するか、パッチを待ってください — すぐ直ることが多いです。アプリ内フィードバックタブからの報告も助かります。

### タブを長く放置したら反応しなくなった

ページを再読み込みしてください。これは v2.9.0 で修正済みなので、最新版であることを確認してください。

### スラッシュコマンドのトグルはどこ？

**ブラウザツールバーのポップアップ** にあります。サイドバーの設定モーダルではありません。ブラウザツールバーの Better Sidebar アイコンをクリックし、プラットフォームタブを選びます。詳しくは [スラッシュコマンド](/en/guide/ui-customization/slash-commands#turning-it-off) を参照してください。

### Notion が「ページが見つかりません」と言う

インテグレーションはあるのに、どのページにもアクセス権がありません。Notion ではページごとに明示的に接続が必要です。詳しくは [連携](/en/guide/extras/integrations#no-pages-found) を参照してください。
