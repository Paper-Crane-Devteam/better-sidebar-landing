# お気に入り

Favorites タブはシンプルで焦点の定まったビューです。スターを付けた会話だけを表示します。フォルダも階層もなく、いちばん重要なチャットのフラットな一覧がワンクリック先にあります。

## お気に入りにできるもの

会話、プロンプト、スニペットはすべてスターできますが、すべてがここに来るわけではありません。

| 項目 | お気に入りの表示先 |
| --- | --- |
| 会話 | このタブ、および所属フォルダの先頭に浮上 |
| プロンプト | [プロンプト](/en/guide/sidebar/prompts-tab) ツリーの先頭と ⭐ フィルター |
| スニペット | [スニペット](/en/guide/sidebar/snippets-tab) ツリーの先頭と ⭐ フィルター |

Favorites タブは会話のみです。各タブが独自のスター集合を持つので、お気に入りプロンプトが重要なチャット一覧を汚しません。

## Favorites タブの使い方

項目をクリックするとその会話へ直接移動します。現在アクティブな会話はハイライトされます。

各項目にホバーすると ⭐ ボタンが出ます — クリックですぐお気に入り解除し、一覧から外れます。

## フィルター

ヘッダーに 3 つのフィルターがあります。

- **検索** — 会話タイトルでフィルター
- **タグ** — 割り当てタグでフィルター（OR 論理 — 選んだタグのいずれかを持つ項目）
- **種類** — すべて / 会話 / 画像 を循環

これらのフィルターはライブラリタブと同じ動きですが、お気に入りだけにスコープされます。

:::tip
Favorites タブは「作業セット」として優れています。今週使う 5〜10 の会話にスターを付け、ライブラリ全体をスクロールせずに切り替えます。終わったらスターを外します。
:::

## お気に入りのワークフロー

お気に入りはこのタブでは管理しません — *ライブラリタブから* 管理します。

1. ライブラリタブで会話を右クリック → **お気に入りに追加**
2. または会話にホバーし、アクションバーの星アイコンをクリック
3. 会話はすぐ Favorites タブに現れ、ライブラリタブでもフォルダ先頭に浮上します

外すには：右クリック → **お気に入りから削除**、または Favorites タブ自体の星をクリック。

:::tip
ライブラリタブの「お気に入りのみ」フィルター（フィルターバーの ⭐）と組み合わせると、ツリーを離れずに素早く眺められます。Favorites タブは気が散らないアクセスに向きます — フォルダも文脈もなく、スター付きだけ。
:::
