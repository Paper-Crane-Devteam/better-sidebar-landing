## 4. AI Agent 與 Web Agent

- AI 的輸出可能出錯。依賴結果之前請先檢查，尤其是 Agent 整理、重新命名或刪除資料，或是編輯檔案的時候。
- **Web Agent** 會在你的瀏覽器裡、用你已登入的帳號讀取並操作網頁。它執行的操作，例如提交表單、傳送訊息、下單，都是以你的名義完成的，而且可能無法復原。
- Web Agent 的每一步操作都需要你先核准，**你要對自己核准的操作負責**，包括遵守你使用它的網站的條款。
- 請不要在銀行、付款、醫療、帳號安全等頁面，或任何出錯代價很高的地方使用 Web Agent。網頁裡可能藏有專門誤導 AI 的指令（「提示詞注入」）。
- 請不要用本擴充功能違反法律、存取你無權存取的系統，或向任何網站傳送垃圾訊息、進行自動化濫用。
