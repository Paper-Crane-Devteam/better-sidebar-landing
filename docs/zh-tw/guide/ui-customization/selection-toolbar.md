# 選取工具列

在 Gemini 對話中反白選取任意文字，選取區域上方會隨即浮現一個小巧的工具列。支援六種核心動作，精準作用於你選取的內容上。

:::tip
僅限 Gemini 平台。AI Studio 目前的前端結構尚未支援此功能。
:::

## 支援動作一覽

| 動作名稱 | 實際功能 | 預設狀態 |
| --- | --- | --- |
| **引用 (Reference)** | 將選取文字作為引用區塊插入到底部輸入框中 | 開啟 |
| **解釋 (Explain)** | 吩咐 AI 深入拆解並解釋選取的內容 | 開啟 |
| **總結 (Summarize)** | 吩咐 AI 針對選取段落進行精簡摘要 | **關閉** |
| **儲存為片段 (Save as Snippet)** | 將選取的精華段落存入 [片段庫](/zh-tw/guide/sidebar/snippets-tab) | 開啟 |
| **複製 (Copy)** | 帶有完整 Markdown 結構地複製選取內容 | 開啟 |
| **儲存為 Prompt (Save as Prompt)** | 將選取內容儲存至 [提示詞庫](/zh-tw/guide/sidebar/prompts-tab) | 開啟 |

每個動作均可在 **設定 → 介面控制 → 選取工具列** 中單獨開關，且附有總開關。建議關閉不常用的功能 —— 三個按鈕的工具列在點擊時比六個按鈕更加精準高效。

## 引用回覆 (Reference)

這是最實用卻常被低估的功能。

在 AI 的冗長回答中反白選取某個特定論點，點擊 **引用**，該段文字會直接以 Markdown 引用格式填入你的輸入框。接著輸入你的追問即可。

這解決了在長篇回答中追問時「你剛才說的具體指什麼？」引發的歧義。直接引用精確語句，模型絕不會誤解你的上下文。

## 儲存為片段 vs 儲存為 Prompt

- **儲存為片段**：保留值得留存的 AI 優秀回答，格式完好無損地進入片段庫。
- **儲存為 Prompt**：保存你臨時發揮的出色提問句式，隨後可透過 [`/`](/zh-tw/guide/ui-customization/slash-commands) 隨時調用。

## 關閉工具列

若你習慣選取文字來輔助眼球閱讀，且覺得頻繁彈出工具列有所干擾，可在 **設定 → 介面控制 → 選取工具列** 關閉總開關。
