# 無浮水印圖片下載

當 Gemini 生成圖片時，Google 預設會為輸出圖片嵌入一層不可見的 SynthID 浮水印中繼資料，標記該圖片為 AI 生成。Better Sidebar 能夠在下載時幫你去除此自動浮水印，提供純淨未經修改的原始圖片。

## 實際作用

當開啟 **移除自動浮水印 (Remove Auto Watermark)** 設定時：

- 由 Gemini 生成的圖片將以原始格式下載
- 下載的檔案中不會附帶隱形的 SynthID 中繼資料浮水印
- 獲取與模型最初生成完全一致的純淨原檔

## 如何開啟

1. 開啟 **設定**（齒輪圖示或快速鍵 `Alt+Shift+,`）
2. 切換至 **平台** 分頁
3. 在 **附加功能** 區塊中找到 **移除自動浮水印**
4. 將開關切換為開啟

設定將即時生效於後續的所有圖片下載。

:::tip
僅限 Gemini 平台。AI Studio 的圖片生成架構不同，不適用此項處理。
:::

## 重要說明

這裡所指的浮水印是隱形的 *中繼資料浮水印 (SynthID)*，而非印在圖片角落可見的文字 Logo。

:::warning
請謹慎考量浮水印移除的合規性。SynthID 旨在幫助辨識網路上的 AI 生成內容。如果你打算在公共場合或商業專案中公開圖片，請遵守當地法規有關 AI 內容標示的要求。
:::
