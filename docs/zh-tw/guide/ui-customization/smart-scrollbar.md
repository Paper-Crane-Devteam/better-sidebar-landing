# 智慧捲軸 (Smart Scrollbar)

長篇對話往往難以導航，因為瀏覽器自帶的捲軸不會告訴你內容的位置。「智慧捲軸」將其替換為一張真實對話的微縮地圖：每則訊息一個對應項目，當前閱讀的訊息即時高亮，點擊即刻跳轉。

![浮動於 Gemini 對話旁的智慧捲軸](/images/features/smart-scrollbar.png)

:::tip
僅限 Gemini 平台。AI Studio 渲染機制不同，暫不支援。在任一平台上你都可以改用側邊欄內部的 [對話大綱](/zh-tw/guide/sidebar/outline)，大綱更進一步 —— 它能精準定位每則回答內部的各級標題、程式碼區塊與表格。
:::

## 啟用方式

預設為開啟狀態。可在 **設定 → 介面控制 → 附加功能 → 智慧捲軸**，或瀏覽器工具列彈窗的 Gemini 分頁中切換開關。

## 三種展示尺寸

面板具備三種狀態，點擊面板頂部按鈕即可隨意切換：

### 緊湊模式 (Compact - 預設)

一條帶有簡短預覽的精巧面板。足以分辨不同訊息，且完全不干擾視野。

### 展開模式 (Expanded)

點擊展開按鈕，它會變身為完整的 **對話導航大綱** —— 面板更寬，預覽文字更長，使用者與模型發言界線更清晰，並在頂部顯示總訊息數。當對話超過 50 則時建議切換至此模式。

### 收縮為圖示 (Collapsed)

點擊摺疊按鈕，它會收縮為帶有訊息計數徽章的懸浮小圓圈。點擊隨時重新展開。

## 平滑導航跳轉

點擊任意項目，頁面會平滑捲動至該則訊息。當你在網頁中正常捲動時，智慧捲軸的高亮焦點會即時跟隨你的視野位置 —— 雙向保持同步。

## 當大綱與頁面不符時

在分支對話或切換歷史版本後，訊息順序可能偶爾出現錯位。

此時智慧捲軸頂部會出現一個小巧的重新整理按鈕。點擊它會清空擴充功能為 *當前這則對話* 儲存的本地記錄，並重新整理頁面以重新擷取最新結構。Gemini 雲端的對話完全不會受到任何影響。
