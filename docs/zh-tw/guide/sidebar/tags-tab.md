# 標籤管理

標籤為你提供了資料夾之外的第二維度組織維度。一則對話只能隸屬於一個資料夾，但可以同時擁有任意多個標籤。資料夾回答的是「這份檔案存放在哪裡？」，而標籤回答的是「這份內容涉及哪些主題？」。

## 建立標籤

1. 在「標籤 (Tags)」分頁頂部的輸入框鍵入名稱
2. 按下 Enter 或點擊 **+** 按鈕
3. 調色盤彈出 —— 為標籤挑選專屬顏色（或保留預設值）
4. 完成，新標籤即可投入使用

標籤名稱上限為 30 個字元。保持短小精悍 —— 例如「工作」、「Side Project」、「待回顧」、「重要參考」。

## 為對話加上標籤

標籤的套用操作在 **資料庫分頁** 進行，而非在標籤分頁本身。在任一對話上按右鍵 → **標籤** → 勾選所需套用的標籤即可。

你也可以批次打標籤：在資料庫分頁開啟批次模式，勾選多則對話，然後使用底部的「新增標籤」動作。

:::tip
標籤分頁是用來 *維護管理* 標籤本體（建立、重新命名、改色、刪除）的地方；具體 *套用* 到對話時，請在資料庫分頁操作。
:::

## 標籤色彩

每個標籤都可以自訂顏色。色彩會呈現於：
- 標籤分頁中各標籤名稱旁
- 篩選下拉選單中
- 資料庫對話列的醒目徽章中

預設色盤與資料夾色盤完全一致，方便你打造協調和諧的視覺色彩規範。

## 管理標籤

### 重新命名

按右鍵 → **重新命名**。標籤名稱切換為編輯框，輸入新標題後按 Enter。所有已打上該標籤的對話將同步更新。

### 刪除標籤

按右鍵 → **刪除**。刪除標籤會將該標籤從所有被套用的對話上移除，但對話本身完好無損。

:::warning
刪除標籤無法復原。對話依然保留在原處，但兩者之間的標籤關聯將被解除。
:::

## 運用標籤進行精準篩選

- **資料庫分頁** — 點擊標籤圖示（🏷️）展開篩選器，選取一個或多個標籤，畫面即刻只保留符合的對話。
- **收藏分頁** — 同樣支援以標籤過濾星號項目。

標籤篩選採用聯集（OR）邏輯：如果同時勾選了「工作」與「前端」，凡是帶有其中任一標籤的對話都會被列出。

:::tip
高效標籤策略：用資料夾劃分 *專案實體*（客戶 A、客戶 B、個人研發），用標籤標記 *狀態與屬性*（緊急、參考資料、待歸檔）。這樣一來，你能跨越所有資料夾一鍵調出所有標記為「緊急」的對話。
:::

## 委託 AI 助手自動打標籤

手動為 300 則歷史對話打標籤無疑是一件繁瑣的苦差事。[AI 助手](/zh-tw/guide/agent/better-sidebar-agent) 能夠讀取標題與對話正文並進行智慧批次歸納：

> 依據內文為我收件匣中的所有對話打上標籤。優先重複使用現有的標籤，不要無端創造意思相近的重複標籤。在正式執行前請先列出規劃清單供我確認。

最後這句話非常重要。若不加約束，AI 可能會自行發明 `coding`、`code`、`programming`、`dev` 四個相近標籤。明確要求它沿用既有標籤，才能讓標籤庫始終井井有條。

你也可以吩咐它幫你整理現有混亂的標籤體系：

> 檢視我的所有標籤，找出語意重疊或重複的項目，提出合併優化建議，確認後幫我套用。

所有變更在執行前均需確認，且事後支援隨時復原。
