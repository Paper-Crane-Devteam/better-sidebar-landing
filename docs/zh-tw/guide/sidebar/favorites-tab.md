# 收藏

「收藏 (Favorites)」分頁提供極簡而聚焦的檢視：僅列出你標記過星號的對話。沒有多層資料夾、沒有階層干擾 —— 只有一份專屬於重要對話的純粹清單，點擊即開。

## 哪些內容可以被收藏？

對話、提示詞與片段均可被標記星號 —— 但它們不會混雜在此處。

| 項目類型 | 收藏後顯示的位置 |
| --- | --- |
| 對話 | 本分頁，以及在其所屬資料夾頂部置頂 |
| 提示詞 | [提示詞庫](/zh-tw/guide/sidebar/prompts-tab) 頂部置頂，以及專屬 ⭐ 篩選器 |
| 片段 | [片段庫](/zh-tw/guide/sidebar/snippets-tab) 頂部置頂，以及專屬 ⭐ 篩選器 |

收藏分頁專屬於對話。各模組分立維護，確保你的收藏對話清單乾淨純粹。

## 使用收藏分頁

點擊任一項目即可直接開啟對話，當前活躍的對話會高亮顯示。

將滑鼠懸停在對話上時會出現 ⭐ 圖示 —— 點擊可快速取消收藏並從清單中移除。

## 快速篩選

頂部提供三種篩選維度：

- **搜尋** — 依對話標題即時過濾
- **標籤** — 依套用的標籤過濾（OR 聯集邏輯 —— 符合任一所選標籤即顯示）
- **類型** — 依全部 / 對話 / 圖片切換

## 收藏工作流

1. 在資料庫分頁中，於對話上按右鍵 → **加入收藏**，或直接點擊懸停時出現的星星圖示
2. 該對話會立即出現在「收藏」分頁中，並在資料庫所屬資料夾內置頂浮動

若要取消：按右鍵 → **取消收藏**，或直接在收藏分頁中點擊星號。

:::tip
建議將「收藏」當作當週的「工作專區 (Working Set)」—— 標記本週最活躍的 5 到 10 則對話，切換極速流暢；任務完成後取消星號即可。
:::
