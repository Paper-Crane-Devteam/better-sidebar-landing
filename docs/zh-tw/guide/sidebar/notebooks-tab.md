# 筆記本 (Gemini)

「筆記本 (Notebooks)」分頁是你在 Gemini 中管理 Notebooks 功能的大本營。Notebooks 是一種獨特的對話容器 —— 它們宛如專案空間，內部可容納多條子對話討論與多份資料來源。Better Sidebar 為你提供所有筆記本的樹狀檢視，並可向下展開每一本筆記本內部包含的關聯對話。

![筆記本分頁列出已同步的 Gemini Notebooks](/images/features/notebooks.png)

:::tip
本分頁專屬於 Gemini。AI Studio 並無 Notebooks 概念，因此在該平台上不會顯示此分頁。
:::

## 掃描同步你的筆記本

點擊頂部工具列的 **掃描** 按鈕（🔄）。擴充功能會調用 Gemini API 匯入完整的筆記本列表。

當你在 Gemini 原生介面中建立新筆記本時，擴充功能亦會自動在背景偵測並更新資料。

## 瀏覽與過濾

- **即時搜尋** — 點擊 🔍 圖示輸入關鍵字即時過濾
- **標籤篩選** — 依套用於筆記本對話上的標籤進行過濾
- **僅看收藏** — 切換 ⭐ 按鈕僅看已標記星號的筆記本或子對話
- **排序** — 支援字母排序與日期排序

## 操作與管理

### 開啟筆記本

點擊筆記本可在樹狀目錄中展開/摺疊其子對話。若要導航至筆記本主頁面，按右鍵 → **開啟筆記本**（前往 `gemini.google.com/notebook/{id}`），或選擇 **在新分頁中開啟**。

### 刪除筆記本

按右鍵 → **刪除筆記本**。安全確認對話框彈出，確認後會透過 API 徹底從 Gemini 伺服器端永久刪除。

### 發起新的筆記本對話

在筆記本上按右鍵 → **新增 Notebook 對話**。頂部 **新增對話** 按鈕右側的下拉選單亦提供相應選項。

## 設定預設資料夾 —— 自動歸檔

在任一筆記本上按右鍵 → **設定預設資料夾** 並選取目標資料夾。從此由該筆記本發起的所有新對話，都會自動歸類至該資料夾中。

你也可以在資料夾的 **資料夾設定** 中，綁定對應的 Notebook。

:::tip
筆記本本身通常就代表一個具體專案，將其綁定到同名資料夾後，該資料夾就會成為該專案的完整檔案庫 —— 自動容納筆記本對話以及你手動拖入的其他相關資料。
:::

## 筆記本內部子對話

展開任意筆記本即可檢視其內部的各條討論串。這些子對話支援與主資料庫完全一致的操作功能：

- 點擊直接開啟對話
- 按右鍵支援完整動作（重新命名、移動、打標籤、匯出、收藏、刪除）
