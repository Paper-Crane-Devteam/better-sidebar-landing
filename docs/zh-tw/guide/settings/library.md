# 資料庫設定

這三項設定決定了你每次開啟「資料庫」分頁時的預設樣貌。

前往 **設定 → 資料庫**。

## 預設檢視模式

控制進入資料庫分頁時的預設介面：

- **樹狀檢視 (Tree)** — 由你完全掌控的階層目錄樹
- **時間線檢視 (Timeline)** — 依今天 / 昨天 / 過去 7 天 / 過去 30 天 / 歷史月份自動分組

你隨時可以使用快速鍵 `Alt+Shift+T` 或頂部 **⋯** 選單即時切換。

## 預設排序規則

- **日期 (Date)** — 最近活躍的對話排在最前
- **名稱 (Name)** — 按字母順序排列

無論選擇何種排序，被標記為收藏的對話與置頂的資料夾始終固定在同層級的最頂端。

## 忽略的資料夾名稱 (Ignored Folders)

輸入以半形逗號分隔的資料夾名稱清單，被列入的資料夾及其內部所有對話將徹底從目錄樹中隱藏。

```
archive, 封存, 舊專案
```

符合名稱的資料夾只是被隱藏，**絕不會被刪除** —— 從清單中移除該名稱後，資料夾與內容立刻原封不動恢復顯示。字數上限 200 字元。

:::tip
當你有想要長久保存卻不想日常看見的歸檔資料時，這是最理想的工具。將過期專案移入「封存」資料夾並填入此處，側邊欄立刻重獲清爽。
:::
