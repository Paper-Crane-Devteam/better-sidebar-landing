# 平台管理工具

點擊瀏覽器工具列上的 Better Sidebar 圖示，會展開一個帶有三個分頁的精緻彈窗。這是存取各平台介面設定最便捷的入口，也是單獨為特定網站徹底關閉擴充功能的唯一位置。

![包含平台、Gemini 與 AI Studio 分頁的瀏覽器工具列彈窗](/images/features/platform-popup.webp)

## 「平台」分頁 (Platforms Tab)

為每個支援的網站提供一個總開關：

| 平台名稱 | 網址網域 |
| --- | --- |
| Google Gemini | `gemini.google.com` |
| Google AI Studio | `aistudio.google.com` |

關閉某個平台將使 Better Sidebar **完全停止** 在該網站上運作 —— 沒有側邊欄浮層、沒有任何腳本注入。該網站將呈現如未安裝擴充功能般的純淨原生狀態。你的本地資料完全不會受到任何影響；日後隨時重新開啟，一切設定原樣恢復。

:::warning
請勿將此開關與「切換至原生側邊欄 (`Alt+Shift+Q`)」混淆。後者只是暫時顯示原生側邊欄外觀，背後的資料索引、斜槓命令與 AI 助手仍正常在背景待命；而在此處關閉平台則代表徹底停用所有功能。
:::

## Gemini 與 AI Studio 專屬分頁

這兩個分頁直接鏡像了 **設定 → 介面控制** 中的選項：各項寬度滑桿、元素可見度與附加功能開關。開啟彈窗時會自動選中你當前所在的網站分頁。

### 斜槓命令開關專屬於此

**斜槓命令 (Slash Commands)** 的總開關僅存在於此彈窗中，按平台獨立配置。若你不希望鍵入 `/` 時彈出提示詞庫，請在此處將其關閉。

| AI 助手與工作區助手 | ✅ 支援 | ✅ 支援 |
| 側邊欄寬度調整 | ✅ 支援 | ✅ 支援 |

| Zen 專注模式 | ✅ 支援 | — |

| 智慧捲軸 (Smart Scrollbar) | ✅ 支援 | — |
| 選取文字工具列 | ✅ 支援 | — |
| Gems 與 Notebooks | ✅ 支援 | — |
| 表格自動滿寬 | ✅ 支援 | — |
| 無浮水印圖片下載 | ✅ 支援 | — |
