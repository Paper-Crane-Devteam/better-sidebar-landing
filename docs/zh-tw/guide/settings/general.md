# 一般設定

「一般設定 (General)」頁面包含三個小而關鍵的項目：擴充功能的介面語言、側邊欄快捷按鈕清單，以及刪除操作是否需要二次確認。

點擊齒輪圖示或按下 `Alt+Shift+,`，然後選擇 **一般**。

## 介面語言

Better Sidebar 完整支援 7 種語言的在地化：

| 語言 | 代碼 |
| --- | --- |
| English | `en` |
| 简体中文 | `zh-CN` |
| 繁體中文 | `zh-TW` |
| 日本語 | `ja` |
| Português | `pt` |
| Español | `es` |
| Русский | `ru` |

切換語言會即刻全域生效 —— 包含所有標籤、懸停提示、對話視窗與更新日誌。首次安裝時會自動根據瀏覽器語系自動設定。

此項設定完全獨立於 Google 官方平台當前顯示的介面語言。

## 側邊欄快捷連結

側邊欄底部的一組快捷圖示按鈕，每個項目均附有獨立開關，方便你隱藏平時不常用的按鈕：

**雙平台通用：**
- **收藏 (Favorites)** — 跳轉至「收藏」分頁
- **切換至原生側邊欄 (Switch to Original Sidebar)** — 一鍵切換回平台原生的側邊欄

**僅限 Gemini：**
- **My Stuff** — 前往 Gemini 我的內容
- **Gems** — 前往 Gemini Gems 管理總覽
- **Notebooks** — 前往 Gemini 筆記本總覽

**僅限 AI Studio：**
- **Build** — 前往 AI Studio Prompt 構建頁
- **Dashboard** — 前往儀表板
- **Documentation** — 開啟官方技術文件

## 操作行為設定

### 刪除對話無需確認

**預設為關閉狀態**，且我們強烈建議維持關閉。

若開啟此項，點擊刪除對話時將不再彈出安全確認對話框 —— 點擊的瞬間該對話便會被永久刪除（包含 Google 伺服器端）。

不論此開關是否開啟，批次刪除時始終都會彈出二度確認。

:::warning
這是全擴充功能中唯一可能因一次手誤點擊而造成資料遺失的設定。若需批次整理，請善用「批次模式」，在執行前清晰預覽所有勾選項。
:::
