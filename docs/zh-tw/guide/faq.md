# 常見問題

## 費用與授權

### Better Sidebar 是免費的嗎？

核心整理功能完全免費且持續免費：資料夾、標籤、搜尋、提示詞、片段、Markdown 匯出、本地備份，以及處於唯讀模式的 AI 助手。無需另外註冊帳號。

另有兩款選用的一次性買斷功能包 —— $5 的主題外觀包，以及 $19.99 允許 AI 助手直接採取修改行動的進階功能包。詳見 [功能包與授權](/zh-tw/guide/settings/packs)。

### 它是開源的嗎？

是的，採用 GPL-3.0 開源協議。[前往 GitHub 查看原始碼](https://github.com/Paper-Crane-Devteam/better-sidebar-for-google-ai-studio)。

### 是否有任何按月訂閱費用？

沒有。兩個功能包均為終身一次性買斷，並享有 7 天無條件退款承諾。

### 我的授權序號可以在多少台電腦上使用？

每個授權包含 10 次啟用額度，每個 *瀏覽器設定檔 (Browser Profile)* 消耗一次啟用。同一個瀏覽器內部 Better Sidebar 自己的多帳號切換不消耗額外額度。詳見 [啟用名額說明](/zh-tw/guide/settings/packs#啟用名額)。

## 隱私與資料安全

### 我的資料儲存在哪裡？

完全儲存在你的瀏覽器本地 SQLite 資料庫中（透過 WASM 與 OPFS 支援）。Better Sidebar 沒有任何自己的伺服器。請參閱 [隱私權政策](/zh-tw/privacy)。

### AI 助手會將我的資料傳送到其他地方嗎？

AI 助手完全透過你現有的 Gemini 或 AI Studio 會話執行。無需 API 金鑰、無額外費用，亦無任何第三方伺服器中轉。

傳送給 Google 的內容，與你在輸入框手動打字一模一樣：包含提示詞以及助手為了回答問題而讀取的本地資料。這是基於大型語言模型運作的必然過程 —— 但資料絕不會流向 Google 之外的任何地方。

### 為什麼擴充功能需要網域主機權限？

為了在 Gemini 與 AI Studio 頁面上正常執行：注入側邊欄浮層、讀取對話標題與 ID，並擷取訊息內文以建立搜尋索引。擴充功能僅會請求這兩個網站的權限。

Notion API 存取屬於 *獨立的選用權限*，僅在你主動啟用 Notion 整合時才會請求。

## 支援平台

### 它是否同時支援 Gemini 與 AI Studio？

是的。部分功能專屬於特定平台，因為兩個網站的架構不同 —— Zen 模式、智慧捲軸、選取工具列、Gems 與 Notebooks 僅限 Gemini；批次歷史匯入僅限 AI Studio。詳見 [平台差異對照表](/zh-tw/guide/settings/platform-manager#平台功能差異)。

### 它是否支援 ChatGPT 或 Claude？

目前尚未支援。

### 支援哪些瀏覽器？

Chrome 以及所有 Chromium 核心瀏覽器（Edge、Brave、Arc、Vivaldi）可直接透過 Chrome 商店安裝，Firefox 則透過 Firefox 附加元件安裝。

請注意，Google Drive 同步功能在 Firefox 上無法使用 —— 該功能需要依賴 Firefox 未開放的專用 Identity API。[本地備份](/zh-tw/guide/extras/data-backup) 則在所有瀏覽器上均可使用。

### 無痕模式 (Incognito) 下能用嗎？

預設情況下瀏覽器擴充功能不會在無痕模式中執行，除非你在瀏覽器的擴充功能管理設定中手動開啟。即使開啟，無痕工作階段中儲存的資料也可能不會持久保存。

### 它會拖慢 Gemini 的運作速度嗎？

不會。它是純介面浮層配合本地 SQLite 運作，核心操作無任何網路等待延遲。

## 找不到資料 / 同步問題

### 我的舊對話沒有出現在側邊欄中

擴充功能預設只能抓取到平台當前載入的近期對話。請點擊 **⋯ 選單 → 匯入聊天記錄清單** 以拉取完整清單。詳見 [保持樹狀目錄同步](/zh-tw/guide/sidebar/library-tab#保持樹狀目錄同步)。

### 搜尋找不到舊對話

匯入聊天記錄清單只會抓取 *標題*，不會包含 *訊息內文*。全文搜尋需要實際的訊息內容，這需要額外步驟建立：

- **AI Studio** — 透過 Google Drive 匯出包進行批次匯入
- **Gemini** — 當你開啟對話時會自動記錄，或者吩咐 [AI 助手](/zh-tw/guide/agent/better-sidebar-agent#回補搜尋索引) 批次為你同步

詳情請參閱 [搜尋指南](/zh-tw/guide/sidebar/search-tab#匯入聊天記錄)。

### 部分舊對話同步顯示為空

非常早期的舊對話有時在 Google 伺服器端已無法被檢索。AI 助手會如實回報哪些對話為空，而不會假裝成功。在這種情況下無法救回內容。

### 大綱顯示的內容與畫面上不一致

這通常發生在分支對話或切換版本之後。使用 [智慧捲軸](/zh-tw/guide/ui-customization/smart-scrollbar#當大綱與頁面不符時) 上的清空並重新載入按鈕，即可重建該對話已儲存的訊息結構。

## AI 助手

### 我需要準備 API Key 嗎？

完全不需要。它直接利用你當前瀏覽器中已登入的對話工作階段。

### 它會消耗我的 Token 配額嗎？

沒有單獨的費用或配額。它就像你自己正在與模型正常對話一樣 —— 因為其本質就是如此。

### 它會不小心刪除我的資料嗎？

所有寫入或修改操作預設均會先徵求你的同意，且在執行改變資料的任務後會提供 **復原變更 (Undo changes)** 按鈕。復原視窗會在開始下一個新任務時關閉。批次刪除前系統亦會自動先建立 [本地快照備份](/zh-tw/guide/extras/data-backup)。

詳見 [掌控與安全護欄](/zh-tw/guide/agent/overview#掌控與安全護欄)。

### 助手突然中斷並提示它偵測到迴圈？

這是刻意設計的保護機制。引擎會自動偵測重複相同的工具呼叫或連續失敗，並主動中止而不是無止境空轉。請閱讀它已完成的部分，然後微調語句重新發起。詳見 [自動防護中斷](/zh-tw/guide/agent/overview#自動防護中斷)。

### 它暫停並提示「已自主完成 12 步」？

這是一次常規的確認簽入，而不是錯誤。在經過較長時間的自主執行後，它會自動暫停以讓你檢視進度，再決定是 **繼續執行** 還是 **在此停止**。

## 資料安全

### 如果我清除了瀏覽器資料會怎樣？

Better Sidebar 的本地資料庫也會一併被清除。你可以透過開啟 [Google Drive 同步](/zh-tw/guide/extras/drive-sync) 或偶爾手動匯出資料庫來防範這一點。

請注意，Drive 同步不包含完整的對話訊息內文 —— 若要完整保存，請前往 **設定 → 資料與儲存 → 匯出** 下載完整資料庫。

### 我可以把資料轉移到另一台電腦嗎？

可以，兩種方式：Drive 同步（僅架構與設定，不含內文）或資料庫匯出/匯入（包含一切完整資料）。詳見 [備份與還原](/zh-tw/guide/extras/data-backup)。

### 在 Better Sidebar 裡刪除對話，Google 上的也會被刪除嗎？

是的。刪除操作是真實的伺服器端同步刪除。如果你只是希望它不要在側邊欄佔空間，可使用支援平台上的 **隱藏** 功能。

## 疑難排解

### 側邊欄沒有出現

1. 確認你在該頁面已登入 Google 帳號 —— 擴充功能與帳號綁定
2. 檢查瀏覽器工具列圖示的 [平台管理工具](/zh-tw/guide/settings/platform-manager) 是否關閉了該平台
3. 重新整理頁面
4. 確認瀏覽器已啟用該擴充功能

### 之前一直正常，今天突然無法使用

通常是 Google 平台調整了前端介面。更新擴充功能，或等待修補程式釋出 —— 我們通常會迅速修復。透過擴充功能內的意見回饋分頁回報會有很大幫助。

### 分頁閒置很久後側邊欄沒有反應

重新整理分頁即可。此問題在 v2.9.0 已經大幅優化，請確保你的擴充功能保持在最新版本。

### 斜槓命令開關在哪裡？

在 **瀏覽器工具列圖示彈窗** 中，而不是在側邊欄內部的設定視窗。點擊瀏覽器工具列上的 Better Sidebar 圖示，切換到對應平台分頁即可開關。詳見 [斜槓命令](/zh-tw/guide/ui-customization/slash-commands#關閉功能)。

### Notion 提示「找不到頁面」

你的整合金鑰雖然正確，但尚未授予任何 Notion 頁面的存取權限。Notion 要求必須手動將整合連結到具體頁面。詳見 [Notion 整合指南](/zh-tw/guide/extras/integrations#找不到頁面)。
