# AI Agent 概覽

Better Sidebar 內建了強大的 AI 助手。你只需用日常大白話描述任務，它就會自行拆解步驟、連續調用本地工具執行，並回報結果。

最關鍵的是：它完全 **透過你當前已登入的 Gemini 或 AI Studio 會話** 運作。無需填寫任何 API Key、無需購買額外 Token，亦無任何第三方伺服器涉入。為你服務的正是你正在聊天的原生模型，你的資料始終留在瀏覽器本地。

![AI 助手執行任務：建立資料夾、移動對話、批次打標籤](/images/features/agent-in-action.png)

## 兩大助手模式

它們具備不同的職責與工具集，發起任務時可依需求選擇其一：

| 助手模式 | 作用範圍 | 專屬指南 |
| --- | --- | --- |
| **Better Sidebar** | 你的對話、資料夾、標籤、提示詞、片段庫 | [Better Sidebar 助手](/zh-tw/guide/agent/better-sidebar-agent) |
| **Workspace (工作區)** | 私有本地工作區中的本機檔案與文件 | [工作區助手](/zh-tw/guide/agent/workspace-agent) |

Better Sidebar 助手無法存取你的本地工作區檔案；工作區助手則無法檢視你的對話庫存。這種嚴格的職責分離是刻意設計的 —— 確保各助手的權限邊界清晰、安全且容易理解。

## 發起任務

在任何聊天輸入框中輸入 `>`。畫面上會彈出選取器，挑選助手模式後，輸入你的任務指令並按下 Enter。

![包含操作說明與範例提示詞的 Agent 分頁](/images/features/agent-launcher.png)

這就是全部的呼叫介面。沒有多餘的獨立對話視窗，因為助手是直接在同一對話流中調用模型來完成任務。

:::tip
側邊欄中的 **Agent** 分頁是一個功能發起站，而非聊天視窗。它匯聚了使用範例、提示詞範本，以及自訂技能與工作區設定的入口。真正的互動直接在網頁原生的輸入框中完成。
:::

### 提示詞範例

Agent 分頁內建了一系列實用範例 —— 整理歷史紀錄、深度穿透搜尋、批次匯出、同步遺失記錄、重構提示詞庫、清理片段、記錄重大決定、分析統計數據。點擊任一範例即可填入輸入框，發送前可隨意修改。

:::tip
指令越明確，結果越精準。「幫我整理對話」通常效果有限。而「將我收件匣中未分類的對話按主題歸納，先給我看規劃方案，只有在現有資料夾不適用時才建立新資料夾，並優先重複使用現有標籤」則能精準交付你心中所想。
:::

## 即時監控執行進度

### 頂部懸浮狀態列 (Agent Dock)

任務執行期間，聊天輸入框上方會浮現常駐狀態列 —— **Agent Dock**。即使關閉側邊欄它依然保持可見，集中呈現當前狀態、停止按鈕、授權確認提示與最終結算摘要。

### 助手檢視 vs 原生檢視

左上角開關可隨時切換對話呈現模式：

- **助手檢視 (Agent)** — 將各步驟渲染為乾淨易讀的操作卡片，結果預設摺疊收納
- **原生檢視 (Original)** — 顯示未經包裝的原生 JSON 請求與模型通訊全文，便於深入排查除錯

### 步驟卡片

每個動作都會以淺顯易懂的卡片展示 —— *檢索資料中*、*修改資料中*、*讀取對話內容*、*匯出中* —— 並標示即時狀態：執行中、已完成、失敗、已拒絕、未執行。點擊任一卡片可隨時查看內部實際運行的詳細細節。

## 掌控與安全護欄

給予 AI 資料庫操作權限時，安全煞車機制是重中之重。

### 讀取直接執行，寫入主動徵詢

預設安全規範：

| 行為設定 | 預設狀態 | 說明 |
| --- | --- | --- |
| **直接執行查詢而無需詢問** | 開啟 | 唯讀查詢（SELECT 等）自動安全運行 |
| **未經許可不得直接修改資料** | **關閉** | 任何新增、修改或刪除操作必須先彈出確認 |
| **自主連續執行** | 開啟 | 步驟自動串連執行；關閉時每一步均需你按 Enter |

### 授權確認視窗

當遇到寫入或修改操作時，Dock 會明確呈現其意圖。你可以選擇：

- **執行** 當前步驟
- **一併執行接下來的 N 個操作** — 批次批准該輪剩餘動作
- **本次任務不再詢問** — 僅在當前單次任務內放行自動執行
- **拒絕**，並可附帶說明原因供模型修正思路

「本次任務不再詢問」只對當前任務有效，下一次新任務發起時會自動恢復嚴謹審批。

### 復原變更 (Undo changes)

在執行過資料修改的任務結束後，總結摘要中會出現 **復原變更** 按鈕。點擊可將所有受影響的資料表即刻復原至任務開始前的原始狀態。

:::warning
復原具有時效性：它持續有效直到你開啟 *下一個* 新任務，或點擊 **保留變更**。若對任務成果存疑，請務必在開啟新任務前做出決定。

此外，復原是整表回滾，這段期間你手動進行的其他修改也會一併被復原。復原後請記得告知模型，以免模型基於已被復原的舊狀態繼續推論。
:::

批次刪除前，系統均會強制先在本地自動建立 [快照備份](/zh-tw/guide/extras/data-backup)。

### 自動防護中斷

引擎內建專門的死迴圈與異常偵測防護：

| 觸發防護條件 | 行為機制 |
| --- | --- |
| **重複無效調用** | 相同工具搭配完全相同參數 —— 嘗試 3 次發出警告，達 5 次強制中止 |
| **連續失敗** | 連續多輪出錯 —— 逐級提升提示介入，連續 6 次強制中止 |
| **無法解析的回覆** | 重新嘗試 1 次，若仍失敗則停止並交由人工接管 |
| **長時間無人值守執行** | 連續無人工介入運行 20 輪後，自動暫停並發起確認簽入 |

## 免費版與進階版功能對比

| 功能項目 | 免費版 | [Power Pack 進階包](/zh-tw/guide/settings/packs) |
| --- | --- | --- |
| 讀取資料、穿透搜尋、分析統計、產出報表 | ✅ 支援 | ✅ 支援 |
| 主動修改資料 —— 歸類、打標籤、改名、合併、清理 | 唯讀建議 | ✅ 支援直接動手執行 |
| 批次匯出到 Obsidian 與 Notion | ❌ | ✅ 支援 |
| 工作區 (Workspace) | 1 個（最多 5 個檔案） | 無限制 |

在免費模式下，助手處於唯讀狀態，但依然非常實用 —— 它能幫你統計哪些資料夾已荒廢、哪些提示詞從未使用過，並列出收件匣每則對話的最佳歸宿建議。

## 隱私承諾

- 直接利用已登入的 Gemini 或 AI Studio 會話，無需 API Key
- 無任何額外開銷或獨立 Token 計費
- 所有查詢均在瀏覽器本地的 SQLite 資料庫中運行
- 絕不會傳送到 Better Sidebar 的任何伺服器（我們根本沒有伺服器）
