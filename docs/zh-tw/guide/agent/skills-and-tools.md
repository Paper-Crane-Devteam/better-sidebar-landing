# 技能與工具清單

在 **設定 → Agent** 中，你可以精準配置每位助手允許執行的操作範圍及其攜帶的指令規範。

頁面按助手維度分別劃分，確保各自職責與邊界涇渭分明。

## 授權與審批政策

這三組核心開關常駐於 Agent Dock 懸浮列中的「權限設定」下，適用於任何正在執行的任務。

| 開關項目 | 預設狀態 | 實際作用 |
| --- | --- | --- |
| **直接執行查詢而無需詢問** | 開啟 | 唯讀查詢（SELECT 等）自動安全運行 |
| **未經許可不得直接修改資料** | **關閉** | 任何修改、刪除或新增動作均會先停下來徵求你的批准 |
| **自主連續執行** | 開啟 | 步驟自動串連執行；關閉時每一步都需要你按 Enter 確認 |

### 為什麼唯讀查詢預設為開啟？

若每一次資料庫檢索（如查詢資料夾 ID 或比對標籤名稱）都要手動彈出確認，助手將完全無法流暢工作。純讀取操作絕不會破壞任何現有資料，因此預設允許自主運作。

### 為什麼修改資料預設必須審批？

因為寫入具有破壞性可能。一句語意模糊的指令如果不慎將幾十則對話重新命名，挽回成本很高。因此預設要求在實際動手前必須由你親自過目確認。

### 獨立的「自主連續執行」開關

這項設定關注的是「迴圈是否允許無人值守自動推進」。關閉它之後，你可以在每一步執行完畢後先仔細閱讀模型的思考推論過程，再按下 Enter 允許它進行下一動作。

## 工具群組

### Better Sidebar 助手工具群組

**Better Sidebar 資料庫工具** —— 查詢與修改對話、資料夾、標籤、提示詞與片段庫。

| 工具名稱 | 具體功能 |
| --- | --- |
| `execute_sql` | 對瀏覽器本地 SQLite 資料庫執行查詢或修改 |
| `sync_conversation_messages` | 開啟並記錄尚無內文記錄的對話歷史訊息 |
| `export` | 將對話打包匯出為本機檔案 |

### 工作區助手工具群組

**純文字與程式碼工具** —— 讀取、編寫、精準替換與全文檢索。

| 工具名稱 | 具體功能 |
| --- | --- |
| `read_file` | 帶行號讀取純文字/程式碼檔案 |
| `write_file` | 建立全新檔案或完整覆寫檔案 |
| `edit_file` | 精準替換檔案內部的指定文字區塊 |
| `list_files` | 瀏覽資料夾目錄 |
| `glob_files` | 依名稱規則尋找檔案 |
| `grep_files` | 正規表達式跨檔案搜尋內文 |
| `manage_files` | 刪除、移動或建立子目錄 |

**富文字文件工具** —— 按大綱與章節精讀並修改 Word、Excel、PDF 與 PowerPoint。

| 工具名稱 | 具體功能 |
| --- | --- |
| `doc_read` | 讀取文件大綱、段落章節與特定搜尋 |
| `doc_edit` | 套用變更 —— 批註、修訂追蹤、儲存格數值、頁面標記 |

## 技能體系 (Skills)

技能是預先封裝的專家指令卡。助手在遇到相符任務時會自動載入相應規則。

### 撰寫自訂技能

在目標助手下方點擊 **新增技能**，包含四個設定項：

| 欄位 | 說明 |
| --- | --- |
| **標題** | 技能名稱，如「每週收件匣整理」 |
| **描述** | 一句話概述功能 —— 助手依據此描述決定何時載入該技能 |
| **提示詞內容** | 具體的執行指令與規範步驟 |
| **常駐載入 (Always on)** | 是否在每次啟動該助手時強制載入 |

最多支援建立 20 個自訂技能。

### 優秀技能範例

技能的價值在於將反覆重複的高頻工作流固定下來：

```markdown
## 任務：每週收件匣整理

整理目前位於 Inbox 收件匣中的所有對話。

執行步驟：
1. 列出收件匣中的所有對話與其日期，並在採取行動前先回報總數。
2. 依主題分組。優先比對現有資料夾 —— 僅在現有資料夾確實無法容納時才提議建立新資料夾。
3. 以表格形式呈現建議的歸檔對應方案，並等待使用者審批。
4. 獲得批准後，執行移動並套用標籤。優先沿用既有標籤，嚴禁創造語意近似的重複標籤。
5. 最終回報整理結果摘要，以及無法確定歸類的項目。
```
