# Better Sidebar 助手

這款助手專門負責管理你的資料庫資產：對話、資料夾、標籤、提示詞與片段庫。它能直接向本地 SQLite 資料庫發起查詢，解答任何預設過濾器無法涵蓋的複雜問題，並依指令採取行動。

在聊天輸入框輸入 `>` 並選擇 **Better Sidebar** 即可啟動。

![AI 助手建立資料夾、移動對話與打標籤，每個步驟以卡片清晰呈現](/images/features/agent-in-action.webp)

## 它的權限與能力邊界

| 操作對象 | 支援動作 |
| --- | --- |
| 對話 (Conversations) | 讀取標題、時間、所屬資料夾、備註說明、訊息內文 |
| 資料夾 (Folders) | 建立、重新命名、移動、修改顏色、刪除 |
| 標籤 (Tags) | 建立、重新命名、套用關聯、合併清理 |
| 提示詞 (Prompts) | 閱讀、改寫、重構組織，包含變數設定與模組化引入 |
| 片段 (Snippets) | 閱讀、重寫標題、重新歸檔、去除重複項目 |

此外，它還具備三項專屬能力：**同步對話訊息**（開啟對話以記錄其正文）、**匯出對話**至本機檔案，以及**啟動專屬技能**載入特殊指令。

它無法存取你的本地工作區檔案 —— 那是 [工作區助手](/zh-tw/guide/agent/workspace-agent) 的專屬職責。

## 內建技能庫

技能是一組預先封裝的專案專家指令集。當任務符合時助手會自動動態載入：

| 內建技能 | 應用場景 |
| --- | --- |
| **自動分類對話 (Auto-Classify Conversations)** | 依據對話內文主題，自動歸類進資料夾並套用標籤 |
| **回補搜尋索引 (Sync Missing Messages)** | 搜尋沒有儲存正文的對話，並逐一自動開啟同步補全 |
| **匯出對話 (Export Conversations)** | 條件查詢並批次匯出對話資料 |
| **管理提示詞庫 (Manage Prompt Library)** | 編寫、重構與組織提示詞，處理變數與模組化組合引入 |
| **管理片段庫 (Manage Snippets)** | 整理、去除重複並搜尋已儲存的精華片段 |

各項技能均可手動停用，且支援自行撰寫擴充。詳見 [技能與工具設定](/zh-tw/guide/agent/skills-and-tools)。

## 經典 Prompt 範例

這些範例非常值得完整閱讀。其句式經過精心打磨 —— 每一句都對目標高度具體，並防範了潛在的邊界偏差。

### 整理堆積未分類的對話

> 整理我未分類的對話：依主題分組，並先列出方案讓我確認。若現有資料夾不適合，才建立新資料夾並將對話移入。最後根據對話內容打上標籤，請優先重複使用現有標籤以避免重複。

### 深度穿透搜尋

> 尋找所有提到「Docker 部署」的內容。請徹底搜尋對話、訊息內文與程式碼片段，不要只搜尋標題。由新到舊排序，為每筆結果提供一句話重點摘要，並註明存放於哪個資料夾。

### 回補搜尋索引

> 檢查有多少對話僅有標題而無儲存訊息。先依最近時間排序回報總數，然後幫我同步最新的 20 則內容，讓它們出現在搜尋與匯出中。

### 批次匯出與封存

> 將「工作」資料夾中 3 月份以來的所有對話匯出為 Markdown，每則對話一個獨立檔案並打包成 ZIP。若有任何對話尚未同步訊息內文，請在匯出前先行告知。

### 重構提示詞庫

> 整理我的提示詞庫：將不容易透過 `/` 檢索的項目重新命名，關鍵詞放最前面。將重複出現的「身分設定與輸出格式」區塊提取成獨立提示詞並以 import 引入。若變數選項固定，請改為下拉選單。

### 清理片段庫

> 我的片段收件匣堆積了很多內容。請依主題將它們分門別類放進資料夾，並將標題簡化為重點摘要。若有重複內容，請保留最舊的一則。刪除前請先列出確認清單。

### 資料庫審計與統計

> 為我製作一份統計報表：每個資料夾有多少對話、上個月新增了多少對話，以及哪些資料夾超過三個月未曾活躍。以此為基礎，建議我哪些資料夾應該合併。

## 連續多輪自然交談

助手會維護上下文記憶。後續對話中無需再次輸入 `>`，直接自然說話即可：

> 有意思。請按月份進一步細分。
> 
> 現在對標記星號的對話也執行一次。
> 
> 算了，不如直接將那兩個資料夾合併吧。

將它視為身旁的實習搭檔，而非生硬的命令列工具。你隨時可以向它諮詢意見：

> 看看我的資料庫，告訴我有哪些地方需要整理？

## 免費版 vs Power Pack 進階包

在免費方案下，助手處於 **唯讀狀態**。所有資料庫檢索、統計分析均正常運作，只是無法直接動手修改你的資料。

即使是唯讀模式，它依然是一名優秀的分析師。它能幫你找出荒廢的資料夾、統計使用習慣，並列出整理建議。

[Power Pack 進階包](/zh-tw/guide/settings/packs) 則全面解鎖主動修改權限。當遇到權限限制時，助手會明確提示，絕不產生模糊混亂的錯誤。
