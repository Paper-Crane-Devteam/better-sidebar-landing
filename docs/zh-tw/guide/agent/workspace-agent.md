# 工作區助手 (Workspace Agent)

「工作區 (Workspace)」是與擴充功能共存的私有檔案空間。你可以將檔案拖曳進去，或者吩咐助手從零開始構建，它能夠直接讀取、編寫與精準修改這些真實檔案。

在聊天輸入框輸入 `>` 並選擇 **Workspace** 即可啟動。

:::tip Beta 測試階段
工作區助手目前處於 Beta 階段。它已具備強大功能且對待檔案極其謹慎，但在邊界情況下仍可能遇到細節瑕疵。回報的問題通常能獲得迅速修復。
:::

## 為什麼它與一般「在對話中上傳附件」截然不同？

當你在對話中上傳一份 Word 檔作為附件時，模型讀取後會在回覆中給你輸出一段全新的文字。當你手動複製貼回原本的文件時，你原有的排版、樣式與字型設定往往蕩然無存。

**工作區助手直接編輯原始檔案本體**。你的標題階層樣式、自動編號、學術引用、統計圖表、條件式格式設定 —— 一律完好如初。因為它只針對你要求調整的段落進行局部修改，檔案其餘二進位部分完全保持一模一樣。

這正是該功能的核心精髓所在。

## 如何將檔案載入工作區？

兩種途徑：

**直接拖放** 進工作區檔案目錄樹。對於 Word、Excel、PDF 與 PowerPoint，必須透過此方式載入，因為瀏覽器端無法憑空從零產生這些複雜的二進位結構。

**吩咐助手從零建立**。對於純文字與各類程式碼檔案，你無需手動上傳任何內容：

> 幫我從零構建一個完整的 React 待辦事項 Todo 應用程式。

助手會直接在工作區中建立 HTML、各元件檔案、CSS 樣式表與設定檔。

:::warning
這是該功能最常見的誤解。許多人誤以為必須先上傳檔案才能使用。對於純文字與程式碼 —— `.md`、`.txt`、`.html`、`.js`、`.ts`、`.py`、`.css`、`.json`、`.csv`、`.srt` 等 —— 助手完全具備無中生有的建立與自由修改能力。
:::

## 支援的檔案格式

### 從零建立與自由編輯

所有純文字與原始碼：`.md` `.txt` `.html` `.css` `.js` `.ts` `.jsx` `.tsx` `.py` `.json` `.csv` `.yml` `.sh` `.srt` `.vtt` 等。

針對這些格式，助手具備全方位能力：建立新檔、精確替換字串、正規表達式跨檔案搜尋、重新架構整個目錄結構。

### 讀取、批註與精確局部修改

以下複合二進位格式僅限已存在的實體檔案：

| 格式 | 副檔名 | 支援能力 |
| --- | --- | --- |
| **Word** | `.docx` `.docm` | 按大綱與章節精讀。插入 **修訂追蹤 (Tracked Changes)** 與 **批註 (Comments)**、替換文字、調整段落與樣式、插入或刪除表格與列 |
| **Excel** | `.xlsx` `.xlsm` `.xltx` | 先分析表頭結構再計算。設定儲存格、新增欄位、新增/重新命名工作表、撰寫真實的 Excel 公式 |
| **PDF** | `.pdf` | 讀取頁面文字與書籤。高亮重點、新增附註便利貼、填寫表單欄位、加浮水印、旋轉、刪除、擷取與合併頁面 |
| **PowerPoint** | `.pptx` | 讀取與修改投影片文字、備忘稿、圖形形狀，調整投影片順序 |

## 實踐應用場景

### 審查論文或合約文件

> 逐章閱讀 `thesis.docx`。在論點薄弱處留下批註，並以「修訂追蹤」的方式提出修改建議，不要直接重寫整段文字。

完成後你下載該檔案直接在 Word 中開啟，就像導師或法務主管幫你審閱過一樣，可以逐條點擊「接受」或「拒絕」，你的參考文獻與圖表編號絲毫無損。

### 試算表統計分析

> 讀取 `sales.xlsx`，新增一欄計算月對月成長率 (MoM)，並新增一個摘要工作表按地區統計總額。

助手會寫入 **真正的 Excel 運算公式**，而非死板的數字。日後原始數據變更時，統計數值會自動聯動更新。

### 字幕翻譯與時間軸保護

> 將 `episode-03.srt` 翻譯成日文並潤色語氣。

時間軸標記被視為神聖不可侵犯，一毫秒都不會偏移，確保字幕與影片完全同步。

### 跨對話記錄重大決策

> 將本次對話的結論整理為清單，儲存到工作區中的 `notes/decisions.md`。末尾附加未決問題。若檔案已存在，請以今天日期進行追加，不要覆蓋舊內容。

工作區檔案 **跨越不同對話，且跨越 Gemini 與 AI Studio 兩大平台** 始終存在 —— 在 Gemini 中建立的檔案，切換至 AI Studio 依然能夠讀取與編輯。

## 工作區額度與限制

檔案存放於具名工作區中（預設為 `default`）。

| 功能項目 | 免費版 | [Power Pack 進階包](/zh-tw/guide/settings/packs) |
| --- | --- | --- |
| 工作區數量 | 1 個 | 無限制 |
| 每個工作區檔案數 | 5 個 | 無限制 |

免費版的 5 個檔案足以讓你深度體驗 —— 放入一份主文件加上幾份備忘筆記。
